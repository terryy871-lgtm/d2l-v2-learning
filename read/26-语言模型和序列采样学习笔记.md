## 1. 先用人话理解语言模型

语言模型要学习的是文本中的顺序规律。

比如看到：

```text
time traveller
```

模型应该知道后面可能出现某些词，而不是完全随机猜。

从概率角度看，语言模型是在估计：

```text
P(下一个词元 | 前面的词元)
```

如果是字符级语言模型，就是：

```text
给定前面一些字符，预测下一个字符
```

## 2. 词频分布说明了什么

notebook 先统计一元词频：

```python
freqs = [freq for token, freq in vocab.token_freqs]
```

然后画 log-log 图。

自然语言有一个明显特点：

```text
少数词非常常见，大量词很少出现
```

比如英文中 `the`、`of`、`and` 很常见，但很多具体名词出现次数很少。

这叫长尾分布。

它提醒我们：

```text
语言数据不是均匀分布的，模型会频繁看到常见词，很少看到低频词
```

## 3. 什么是一元、二元、三元

### 一元 unigram

只看单个词元：

```text
"time"
```

### 二元 bigram

看连续两个词元：

```text
"time traveller"
```

### 三元 trigram

看连续三个词元：

```text
"the time traveller"
```

notebook 中用：

```python
zip(corpus[:-1], corpus[1:])
```

构造二元词组。

用：

```python
zip(corpus[:-2], corpus[1:-1], corpus[2:])
```

构造三元词组。

## 4. 为什么 n 元词组越长越稀疏

一元词很多会重复。

但二元组合更具体，三元组合更具体。

所以随着 n 变大：

- 可能组合数量变多
- 每个组合出现频率变低
- 数据变得更稀疏

这就是传统 n-gram 语言模型的一个困难：

```text
上下文越长，统计越稀疏
```

而神经网络语言模型希望通过参数共享和表示学习缓解这个问题。

## 5. 为什么要读取长序列数据

语言模型训练时，不能每次只喂一个字符。

我们通常把长语料切成固定长度的小序列。

比如：

```text
X = [t, i, m, e]
Y = [i, m, e, 空格]
```

也就是让模型在每个时间步预测下一个词元。

所以输入 `X` 和标签 `Y` 的关系是：

```text
Y 是 X 向后移动一位
```

## 6. 随机采样是什么

`seq_data_iter_random` 会从语料中随机抽取子序列。

它的特点是：

```text
不同 batch 之间的子序列不一定连续
```

好处是样本更随机，训练时不太依赖固定顺序。

缺点是：

```text
相邻 batch 之间不能自然延续隐藏状态
```

所以使用随机采样时，通常每个 batch 都要重新初始化隐藏状态。

## 7. 顺序分区是什么

`seq_data_iter_sequential` 会尽量按原始顺序切分语料。

它的特点是：

```text
相邻 batch 在原始语料中保持连续关系
```

这对 RNN 很有用，因为隐藏状态可以从上一个 batch 延续到下一个 batch。

但为了避免计算图无限增长，需要在训练中对隐藏状态做 `detach`。

这会在后面的 RNN 训练代码里出现。

## 8. 两种采样方式的核心区别

### 随机采样

```text
子序列顺序被打乱，batch 之间不连续
```

适合让模型看到更随机的样本。

### 顺序分区

```text
保留语料顺序，batch 之间可以延续状态
```

更贴近 RNN 的时间连续性。

没有绝对谁更好，重点是要知道它们对隐藏状态处理方式有影响。

## 9. `SeqDataLoader` 做了什么

最后封装了：

```python
class SeqDataLoader:
    def __init__(...):
        ...
    def __iter__(self):
        return self.data_iter_fn(self.corpus, self.batch_size, self.num_steps)
```

它把语料、词表、采样方式和 batch 参数封装起来。

外部调用时只需要：

```python
load_data_time_machine(batch_size, num_steps)
```

就能拿到数据迭代器和词表。

这是后面 RNN 训练的基础设施。
