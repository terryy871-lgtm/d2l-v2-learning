## 1. 这一章在学什么

前两章已经知道注意力机制的整体结构：

```text
query 和 key 计算相关性 -> 得到注意力权重 -> 对 value 加权汇总
```

这一章重点回答一个问题：

```text
query 和 key 的相关性到底怎么计算？
```

notebook 中实现了两种方式：

1. 加性注意力
2. 缩放点积注意力

它们都是后面 Bahdanau 注意力、多头注意力和 Transformer 的基础。

## 2. masked_softmax 为什么重要

代码先定义：

```python
def masked_softmax(X, valid_lens):
```

它的作用是在 softmax 前把无效位置遮住。

在序列任务中，句子通常会被 padding 到相同长度：

```text
真实词元 真实词元 <eos> <pad> <pad>
```

`<pad>` 不是有效内容，所以不能被注意力关注。

如果不 mask，模型可能会把一部分注意力分给 padding，这会污染上下文向量。

## 3. masked_softmax 的基本思路

普通 softmax 会对最后一个维度做归一化：

```text
分数 -> 概率权重
```

masked softmax 多做一步：

```python
X = d2l.sequence_mask(X.reshape(-1, shape[-1]), valid_lens, value=-1e6)
```

把无效位置替换成很大的负数 `-1e6`。

softmax 后这些位置会接近 0。

所以最后得到的注意力权重满足：

```text
有效位置正常分配权重
无效位置权重约等于 0
```

## 4. 一维 valid_lens 和二维 valid_lens

代码测试了两种情况。

第一种：

```python
valid_lens = torch.tensor([2, 3])
```

表示每个样本的有效 key 数量。

如果一个 batch 有两个样本，那么第一个样本只看前 2 个 key，第二个样本只看前 3 个 key。

第二种：

```python
valid_lens = torch.tensor([[1, 3], [2, 4]])
```

表示每个样本的每个 query 都可以有不同有效长度。

这在解码器掩蔽自注意力中很常见，因为第 1 个位置只能看自己，第 2 个位置能看前两个位置，依次类推。

## 5. 加性注意力是什么

notebook 中定义：

```python
class AdditiveAttention(nn.Module):
```

加性注意力的核心思想是：

```text
先把 query 和 key 投影到同一个隐藏空间，再用一个小网络计算匹配分数
```

它使用三个线性层：

```python
self.W_k = nn.Linear(key_size, num_hiddens, bias=False)
self.W_q = nn.Linear(query_size, num_hiddens, bias=False)
self.w_v = nn.Linear(num_hiddens, 1, bias=False)
```

其中：

- `W_q`：变换 query
- `W_k`：变换 key
- `w_v`：把融合后的特征压成一个分数

## 6. 加性注意力的形状变化

在 `forward` 中：

```python
queries, keys = self.W_q(queries), self.W_k(keys)
features = queries.unsqueeze(2) + keys.unsqueeze(1)
```

假设：

```text
queries: (batch_size, 查询数, num_hiddens)
keys:    (batch_size, key-value 对数, num_hiddens)
```

扩展维度后：

```text
queries -> (batch_size, 查询数, 1, num_hiddens)
keys    -> (batch_size, 1, key-value 对数, num_hiddens)
```

二者相加会通过广播得到：

```text
(batch_size, 查询数, key-value 对数, num_hiddens)
```

也就是说，每个 query 都会和每个 key 组合一次。

## 7. 加性注意力如何得到输出

代码中：

```python
scores = self.w_v(features).squeeze(-1)
self.attention_weights = masked_softmax(scores, valid_lens)
return torch.bmm(self.dropout(self.attention_weights), values)
```

流程是：

1. `scores` 计算 query-key 匹配分数
2. `masked_softmax` 得到注意力权重
3. `torch.bmm` 对 value 做批量加权求和

最终输出形状是：

```text
(batch_size, 查询数, value 维度)
```

每个 query 都会得到一个上下文向量。

## 9. 缩放点积注意力是什么

第二种实现是：

```python
class DotProductAttention(nn.Module):
```

它直接用 query 和 key 的点积作为相似度：

```python
scores = torch.bmm(queries, keys.transpose(1, 2)) / math.sqrt(d)
```

点积越大，说明 query 和 key 方向越接近。

这种方法计算更高效，非常适合矩阵并行。

Transformer 中主要使用的就是缩放点积注意力。

## 10. 为什么要除以 sqrt(d)

如果向量维度 `d` 很大，点积结果的数值范围也容易变大。

分数太大时，softmax 会变得非常尖锐：

```text
最大的分数接近 1，其他分数接近 0
```

这样会导致梯度不稳定。

所以缩放点积注意力会除以：

```text
sqrt(d)
```

这一步能让分数尺度更稳定。

## 11. 加性注意力和点积注意力怎么选

两者都能计算 query-key 相关性。

加性注意力特点：

- query 和 key 维度可以不同
- 使用小型前馈网络计算分数
- Bahdanau 注意力常用它

点积注意力特点：

- query 和 key 维度需要一致
- 矩阵乘法效率高
- Transformer 常用它

简单理解：

```text
加性注意力更灵活，点积注意力更高效
```

## 12. 这章和后面章节的关系

Bahdanau 注意力会把加性注意力接到 Seq2Seq 解码器里。

多头注意力会把缩放点积注意力并行做多次。

Transformer 会把多头注意力、残差连接、层规范化和前馈网络组合成完整模型。

所以这一章是后面所有注意力模型的“打分函数地基”。
