## 1. 为什么文本需要预处理

神经网络擅长处理数字张量。

但原始文本是字符串，比如：

```text
the time machine
```

模型不能直接对这些字符做矩阵乘法。

所以文本进入模型前，必须经历一个转换过程：

```text
原始文本 -> 词元 -> 词表索引 -> 张量
```

这一章就在做这件事。

## 2. 读取《时间机器》文本

notebook 中先定义了：

```python
d2l.DATA_HUB['time_machine'] = (...)
```

然后读取文本：

```python
def read_time_machine():
    with open(d2l.download('time_machine'), 'r') as f:
        lines = f.readlines()
    return [re.sub('[^A-Za-z]+', ' ', line).strip().lower() for line in lines]
```

这里做了几件事：

1. 下载或读取《时间机器》文本
2. 按行读取
3. 用正则表达式去掉非字母字符
4. 去除首尾空格
5. 转成小写

清洗后的文本更规整，方便后面分词。

## 3. 什么是词元化

词元化就是把文本拆成基本单位。

代码中：

```python
def tokenize(lines, token='word'):
    if token == 'word':
        return [line.split() for line in lines]
    elif token == 'char':
        return [list(line) for line in lines]
```

它支持两种方式。

### 按单词拆

```text
"time machine" -> ["time", "machine"]
```

### 按字符拆

```text
"time" -> ["t", "i", "m", "e"]
```

语言模型可以按词建模，也可以按字符建模。

字符级模型词表更小，但序列更长。

词级模型序列更短，但词表通常更大。

## 4. 什么是词表

词表就是：

```text
词元和整数索引之间的映射表
```

比如：

```text
"the" -> 1
"time" -> 2
"machine" -> 3
```

模型真正看到的不是 `"time"` 这个字符串，而是它对应的索引。

notebook 中的 `Vocab` 类负责构建这种映射。

## 5. `Vocab` 类做了哪些事

`Vocab` 初始化时主要做：

1. 统计所有词元出现频率
2. 按频率从高到低排序
3. 建立 `idx_to_token`
4. 建立 `token_to_idx`
5. 给未知词元 `<unk>` 留出索引 0

这两个属性很重要：

### `idx_to_token`

```text
通过索引找词元
```

### `token_to_idx`

```text
通过词元找索引
```

一个负责从数字还原文本，一个负责把文本变成数字。

## 6. 为什么需要 `<unk>`

`<unk>` 表示 unknown，也就是未知词元。

如果测试文本里出现了训练词表没有见过的词，就可以映射到 `<unk>`。

否则模型会不知道该怎么处理。

这是一种很常见的防守设计：

```text
即使遇到没见过的词，也让输入保持合法
```

## 7. `count_corpus` 在干什么

`Vocab` 里会调用 `count_corpus(tokens)`。

它的作用是统计词频。

如果输入是二维列表，比如每一行都是一个词元列表，就先展平成一维。

然后用：

```python
collections.Counter(tokens)
```

统计每个词元出现多少次。

词频非常重要，因为常见词通常会放在词表前面。

## 8. 文本怎么变成索引

notebook 里演示了：

```python
print('文本:', tokens[i])
print('索引:', vocab[tokens[i]])
```

如果输入是一个词元列表，`vocab[...]` 会返回对应索引列表。

比如：

```text
["the", "time"] -> [1, 20]
```

这一步完成后，文本就变成了模型能处理的整数序列。

## 9. `load_corpus_time_machine` 做了什么

最后封装了：

```python
def load_corpus_time_machine(max_tokens=-1):
    lines = read_time_machine()
    tokens = tokenize(lines, 'char')
    vocab = Vocab(tokens)
    corpus = [vocab[token] for line in tokens for token in line]
    if max_tokens > 0:
        corpus = corpus[:max_tokens]
    return corpus, vocab
```

这一步做的是字符级语料准备。

它返回两个东西：

1. `corpus`：所有字符对应的索引组成的长列表
2. `vocab`：字符和索引之间的映射表

注意这里把所有行展平成一条长序列。

这是因为后面的语言模型要沿着字符顺序学习：

```text
给定前面的字符，预测下一个字符
```

## 10. 这份 notebook 你最应该记住什么

学完这一章，最重要的是记住：

1. 原始文本必须先转换成数字索引
2. 词元化决定文本的基本建模单位
3. 词表负责词元和索引之间的互相映射
4. `<unk>` 用来处理未知词元
5. 字符级语料最终会变成一条很长的索引序列

如果最后只留一句话：

```text
文本建模的第一步不是训练模型，而是先把文字整理成模型能读懂的序列数据
```
