# 24 序列数据处理学习笔记

这份笔记是结合你的文件 [24_Working_with_Sequences.ipynb](</D:/Learn/d2l-test/Recurrent_Neural_Network/24_Working_with_Sequences.ipynb>) 写的，目标是帮助你真正理解：

- 什么是序列数据

- 怎样把一个长序列改造成监督学习样本
- 单步预测和多步预测有什么区别
- 为什么多步预测误差会不断累积

如果用一句话概括这一章：

```text
序列预测的核心是：用过去一段时间的信息，预测未来某个时间点的值
```

## 1. 先用人话理解序列数据

前面你学的很多任务，比如图像分类，输入样本之间通常可以看成相互独立。

但序列数据不一样，它天然带有顺序。

比如：

- 每一天的气温
- 股票价格
- 一句话里的字符
- 用户点击行为
- 传感器读数

这些数据的关键不是单个点，而是：

```text
前后之间有关系
```

所以处理序列数据时，我们不能只问“这个点是多少”，还要问：

```text
它前面发生了什么？
```

## 2. notebook 一开始生成了什么数据

代码里先生成了一条带噪声的正弦曲线：

```python
T = 1000
time = torch.arange(1, T + 1, dtype=torch.float32)
x = torch.sin(0.01 * time) + torch.normal(0, 0.2, (T,))
```

这条序列由两部分组成：

1. `torch.sin(0.01 * time)`：主要规律，是平滑周期变化
2. `torch.normal(0, 0.2, (T,))`：随机噪声，让数据更接近真实情况

所以这份数据不是完全随机的。

它有规律，但规律上叠加了扰动。

这很适合用来理解时间序列预测。

## 3. 为什么要构造 `features` 和 `labels`

神经网络训练需要输入和标签。

但原始序列只有一串数：

```text
x1, x2, x3, x4, ...
```

所以我们要把它改造成监督学习格式。

notebook 里设置：

```python
tau = 4
features = torch.zeros((T - tau, tau))
for i in range(tau):
    features[:, i] = x[i: T - tau + i]
labels = x[tau:].reshape((-1, 1))
```

这里 `tau=4` 表示：

```text
用前 4 个时间步预测下 1 个时间步
```

比如一个样本可以理解成：

```text
输入：[x1, x2, x3, x4]
标签：x5
```

下一个样本是：

```text
输入：[x2, x3, x4, x5]
标签：x6
```

这就是把序列预测转成普通监督学习的关键。

## 4. 训练集为什么只用前 600 个样本

代码中：

```python
batch_size, n_train = 16, 600
train_iter = d2l.load_array((features[:n_train], labels[:n_train]), batch_size, is_train=True)
```

这里只用前 600 个样本训练。

后面的序列点保留下来，用来观察模型在未来时间段上的预测效果。

这和普通训练集、测试集划分有一点区别：

```text
序列任务通常不能随便打乱时间顺序后再划分，否则可能泄漏未来信息
```

在时间序列里，“未来”应该尽量当成模型没见过的数据。

## 5. 这里为什么用 MLP

代码定义了一个简单网络：

```python
net = nn.Sequential(
    nn.Linear(4, 10),
    nn.ReLU(),
    nn.Linear(10, 1)
)
```

这不是循环神经网络，而是一个普通多层感知机。

它的输入固定是 4 个历史值，输出是 1 个预测值。

这说明：

```text
在进入 RNN 之前，我们也可以先用固定窗口方法处理序列预测
```

这种方法简单直观，但缺点是窗口长度固定。

如果长期依赖超过 `tau=4`，这个模型就看不到更远的信息。

## 6. 单步预测是什么

训练完成后，代码先做：

```python
onestep_preds = net(features)
```

这里的每个预测都使用真实历史窗口作为输入。

也就是说预测 `x5` 时用真实的 `[x1, x2, x3, x4]`。

预测 `x6` 时用真实的 `[x2, x3, x4, x5]`。

所以单步预测比较容易。

因为模型每次都站在真实历史数据上往前预测一步。

## 7. 多步预测是什么

多步预测代码是：

```python
multistep_preds = torch.zeros(T)
multistep_preds[: n_train + tau] = x[: n_train + tau]
for i in range(n_train + tau, T):
    multistep_preds[i] = net(multistep_preds[i - tau:i].reshape((1, -1)))
```

这里从某个时间点之后，模型不再总能拿到真实历史值。

它要使用自己前面预测出来的值继续预测未来。

这就是：

```text
用预测喂给预测
```

问题也随之出现：

```text
一旦前面预测错了，后面会把这个错误继续带下去
```

所以多步预测往往比单步预测难得多。

## 8. 为什么预测步数越远越不准

最后一段代码比较了：

```python
steps = (1, 4, 16, 64)
```

也就是 1 步、4 步、16 步、64 步预测。

你会发现预测越远，结果越容易偏离真实曲线。

原因很自然：

1. 单步预测只犯一次误差
2. 多步预测会把前面的误差当成后面的输入
3. 误差会随着预测链条不断积累

所以序列预测里有一个很重要的事实：

```text
短期预测通常容易，长期预测会迅速变难
```

## 9. 这章和 RNN 有什么关系

这一章还没有真正使用循环神经网络。

但它为 RNN 做了铺垫：

- 序列有时间顺序
- 过去的信息会影响未来
- 固定窗口方法只能看固定长度历史
- 多步预测会暴露长期依赖和误差累积问题

RNN 后面要解决的核心就是：

```text
能不能让模型在处理序列时，自动维护一个“历史状态”
```

这个历史状态就是后面会反复出现的隐藏状态。

## 10. 这份 notebook 你最应该记住什么

学完这一章，最重要的是记住：

1. 序列数据的样本之间有时间依赖
2. 可以用滑动窗口把序列预测转成监督学习
3. `tau` 表示模型能看到多少个历史时间步
4. 单步预测使用真实历史，难度较低
5. 多步预测使用模型自己的历史预测，误差会累积

如果最后只留一句话：

```text
序列预测真正难的不是预测下一步，而是在未来越来越远时还能保持稳定
```
