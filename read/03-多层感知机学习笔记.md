## 1. 先用一句人话理解多层感知机

你已经学过：

1. 线性回归
2. Softmax 回归

它们本质上都有一个共同点：

```text
模型整体仍然是线性的
```

比如 Softmax 回归虽然最后用了 softmax，但核心打分层还是：

```text
O = XW + b
```

这意味着模型表达能力有限，它只能学习比较简单的线性边界。

多层感知机（MLP, Multilayer Perceptron）就是为了解决这个问题。

它的思想是：

```text
输入 -> 线性变换 -> 非线性激活 -> 再线性变换 -> 输出
```

关键不是“层数多了”，而是：

```text
中间插入了非线性变换
```

这会让模型有能力学习更复杂的模式。

## 2. 为什么需要隐藏层和激活函数

这是这一章最核心的知识点。

### 2.1 只堆线性层没有意义

假设你写两个线性层：

```text
H = XW1 + b1
O = HW2 + b2
```

把它们展开：

```text
O = (XW1 + b1)W2 + b2
```

继续整理后，本质上仍然可以写成：

```text
O = XW + b
```

也就是说：

```text
多个纯线性层叠在一起，本质上还是一个线性层
```

所以如果没有激活函数，模型虽然“看起来更深”，但本质能力没有真正提升。

### 2.2 激活函数的作用

激活函数的作用是：

```text
给模型引入非线性
```

只有加入非线性以后，模型才有能力表示更复杂的输入输出关系。

所以多层感知机真正强的地方不只是“多了一层”，而是：

- 有隐藏层
- 隐藏层后面接激活函数

## 3. 多层感知机的整体结构

你这份 notebook 对应的是一个最经典的单隐藏层 MLP。

结构可以写成：

```text
输入层(784)
-> 隐藏层(256)
-> ReLU
-> 输出层(10)
```

用公式写：

```text
H = ReLU(XW1 + b1)
O = HW2 + b2
```

其中：

- `X`：输入
- `W1, b1`：第一层参数
- `H`：隐藏层输出
- `W2, b2`：第二层参数
- `O`：输出层打分

如果是分类任务，后面通常再配合交叉熵损失。

## 5.2 初始化模型参数

```python
num_inputs,num_outputs,num_hideens=784,10,256
W1=nn.Parameter(torch.randn(num_inputs,num_hideens,requires_grad=True)*0.01)
b1=nn.Parameter(torch.zeros(num_hideens,requires_grad=True))
W2=nn.Parameter(torch.randn(num_hideens,num_outputs,requires_grad=True)*0.01)
b2=nn.Parameter(torch.zeros(num_outputs,requires_grad=True))
params=[W1,b1,W2,b2]
```

这是从零实现里最重要的一段。

### 先看维度含义

- `num_inputs = 784`
- `num_outputs = 10`
- `num_hideens = 256`

虽然你变量名写成了 `num_hideens`，通常更标准的拼写是 `num_hiddens`，但不影响运行。

### 为什么输入是 784

因为 Fashion-MNIST 每张图片大小是：

```text
28 × 28
```

拉平成一维以后就是：

```text
784
```

### 为什么输出是 10

因为这是 10 分类问题。

输出层要给出每个类别的分数，所以输出维度是 10。

### 为什么隐藏层设置成 256

这是一个人为设定的超参数。

它表示：

- 输入和输出之间插入一个中间表示层
- 这一层有 256 个神经元

这个数不是数学上唯一正确的，而是实验设计的一部分。

### `W1`、`b1`、`W2`、`b2` 分别是什么

第一层：

- `W1`：输入层到隐藏层的权重
- `b1`：输入层到隐藏层的偏置

第二层：

- `W2`：隐藏层到输出层的权重
- `b2`：隐藏层到输出层的偏置

### 形状为什么这样设置

#### `W1`

```python
W1.shape = (784, 256)
```

因为输入 `X` 拉平后形状大致是：

```text
(batch_size, 784)
```

想让它映射到隐藏层：

```text
(batch_size, 256)
```

所以必须满足：

```text
(batch_size, 784) × (784, 256) = (batch_size, 256)
```

#### `b1`

```python
b1.shape = (256,)
```

因为隐藏层每个单元都需要一个偏置。

#### `W2`

```python
W2.shape = (256, 10)
```

因为隐藏层输出是：

```text
(batch_size, 256)
```

要变成输出层：

```text
(batch_size, 10)
```

所以必须满足：

```text
(batch_size, 256) × (256, 10) = (batch_size, 10)
```

#### `b2`

```python
b2.shape = (10,)
```

因为输出层一共有 10 个类别分数。

### `torch.randn(...) * 0.01` 是什么意思

`torch.randn(...)` 表示：

- 从标准正态分布里随机采样

再乘以 `0.01` 表示：

- 把初始参数缩小

这通常是为了让模型一开始的参数不要太大，避免初始输出过于极端。

### `nn.Parameter` 是什么

这是一个非常重要的 PyTorch 语法。

你可以把它理解成：

```text
把一个普通 tensor 包装成“模型参数”
```

这样做以后，这个对象会：

- 被优化器识别
- 被当作需要训练的参数

如果你只是写：

```python
W1 = torch.randn(...)
```

它只是普通 tensor。

而写成：

```python
W1 = nn.Parameter(...)
```

它就变成了“可训练参数”。

### `params=[W1,b1,W2,b2]`

这一步是在把需要训练的参数收集起来，后面优化器会用到。

## 5.3 定义激活函数 ReLU

```python
def relu(X):
    a = torch.zeros_like(X)
    return torch.max(X,a)
```

这一段是多层感知机最关键的新增内容之一。

### ReLU 是什么

ReLU 的数学形式是：

```text
ReLU(x) = max(x, 0)
```

意思非常简单：

- 如果输入大于 0，就保留原值
- 如果输入小于等于 0，就变成 0

例如：

```text
[-2, -1, 0, 3, 5] -> [0, 0, 0, 3, 5]
```

### 代码在做什么

```python
a = torch.zeros_like(X)
```

表示：

- 创建一个和 `X` 形状完全相同的全 0 张量

```python
return torch.max(X, a)
```

表示：

- 对 `X` 和全 0 张量逐元素取最大值

这正好实现了 ReLU。

### 为什么 ReLU 重要

因为它提供了非线性。

没有它的话：

- 两层线性层叠加还是线性模型

有了它以后：

- 模型就能学习更复杂的模式

### 为什么常用 ReLU

因为它：

- 形式简单
- 计算快
- 在很多任务里效果好

它是深度学习里最常见的激活函数之一。

## 5.4 定义模型

```python
def net(X):
    X=X.reshape((-1,num_inputs))
    H=relu(X@W1+b1)
    return (H@W2)+b2
```

这是你手写的多层感知机前向传播。

把它拆开看。

### 第一步：拉平输入

```python
X = X.reshape((-1, num_inputs))
```

原始图片一般是：

```text
(batch_size, 1, 28, 28)
```

这里要把它变成：

```text
(batch_size, 784)
```

`-1` 的意思是：

- 这一维让 PyTorch 自动推断

所以：

```python
X.reshape((-1, 784))
```

就是把每张图拉平成长度为 784 的向量。

### 第二步：第一层线性变换

```python
X@W1 + b1
```

这一步把输入从 `784` 维映射到 `256` 维。

输出形状是：

```text
(batch_size, 256)
```

### 第三步：经过 ReLU

```python
H = relu(X@W1+b1)
```

这里的 `H` 就是隐藏层表示。

它的作用是：

- 把输入先映射到一个新的特征空间
- 再通过非线性激活增强模型表达能力

### 第四步：第二层线性变换

```python
return (H@W2)+b2
```

这一步把隐藏层输出从 `256` 维映射到 `10` 维。

最终输出形状是：

```text
(batch_size, 10)
```

### 注意：这里没有手写 softmax

这是很多初学者会疑惑的点。

你前面 Softmax 回归是显式写了 softmax 的，但这里没有。

原因是你后面用了：

```python
nn.CrossEntropyLoss()
```

这个损失函数内部已经会处理 softmax 对应的逻辑，所以前向传播里不用手动再写一次。

这一点非常重要。

## 5.5 定义损失函数

```python
loss = nn.CrossEntropyLoss(reduction='none')
```

这里你用的是交叉熵损失，适合多分类任务。

### `CrossEntropyLoss` 是干什么的

它适用于：

- 输出是多个类别分数
- 标签是类别编号

对你这个任务来说正合适。

### 为什么它适合这里

因为你的模型最终输出的是：

```text
(batch_size, 10)
```

表示每个样本对应 10 个类别的打分。

标签则通常是：

```text
(batch_size,)
```

每个值是 `0~9` 之间的类别编号。

### `reduction='none'` 是什么意思

这是一个很重要的参数。

它表示：

- 不要立刻把一个 batch 的所有损失做平均或求和
- 而是保留每个样本自己的损失

例如一个 batch 有 256 个样本，那么：

```text
loss(y_hat, y)
```

得到的通常是长度为 256 的损失向量。

后面训练函数再决定：

- 是求和
- 还是求平均

### 为什么这里不用手写 softmax + cross entropy

因为 `nn.CrossEntropyLoss` 已经是 PyTorch 官方封装好的分类损失。

通常它期待输入的是：

- 原始分数 logits

而不是你手动 softmax 之后的概率。

所以你现在这份代码是更标准的写法。

## 5.6 定义优化器并训练

```python
num_epochs,lr=10,0.1
updater = torch.optim.SGD(params,lr=lr)
d2l.train_ch3(net, train_iter, test_iter, loss, num_epochs, updater)
```

这一段是在正式训练模型。

### `torch.optim.SGD` 是什么

它是 PyTorch 自带的随机梯度下降优化器。

你可以理解成：

```text
根据参数的梯度，自动更新参数
```

### `torch.optim.SGD(params, lr=lr)` 的意思

- `params`：告诉优化器，哪些参数需要更新
- `lr=lr`：学习率是多少

### 训练流程虽然模型变复杂了，但主线不变

这里还是：

1. 前向传播得到预测
2. 用损失函数衡量误差
3. `backward()` 计算梯度
4. 优化器更新参数

也就是说：

```text
多层感知机虽然比 Softmax 回归复杂，但训练套路没有变
```

## 7.2 用 `nn.Sequential` 定义模型

```python
net = nn.Sequential(nn.Flatten(),nn.Linear(784,256),nn.ReLU(),nn.Linear(256,10))
```

这一句是后半部分最关键的代码。

### `nn.Sequential` 是什么

你可以把它理解成：

```text
把多个层按顺序串起来，前一层输出自动作为后一层输入
```

也就是说：

```python
nn.Sequential(A, B, C)
```

大致等价于：

```python
x = A(x)
x = B(x)
x = C(x)
```

### `nn.Flatten()`

作用是：

- 把输入图片拉平

例如：

```text
(batch_size, 1, 28, 28) -> (batch_size, 784)
```

它相当于你手写版里的：

```python
X.reshape((-1, num_inputs))
```

### `nn.Linear(784,256)`

作用是：

- 做一个线性层
- 输入维度 784
- 输出维度 256

它相当于手写版里的：

```python
X@W1 + b1
```

### `nn.ReLU()`

作用是：

- 调用 ReLU 激活函数

它相当于手写版里的：

```python
relu(...)
```

### `nn.Linear(256,10)`

作用是：

- 把隐藏层映射到输出层

它相当于手写版里的：

```python
H@W2 + b2
```

所以整句：

```python
nn.Sequential(nn.Flatten(),nn.Linear(784,256),nn.ReLU(),nn.Linear(256,10))
```

完整对应手写版：

```python
X -> reshape -> 线性层1 -> ReLU -> 线性层2
```

## 7.3 初始化权重

```python
def init_weights(m):
    if type(m) == nn.Linear:
        nn.init.normal_(m.weight,std=0.01)
net.apply(init_weights)
```

这部分是在自定义初始化方式。

### `init_weights(m)` 在做什么

这个函数的意思是：

- 如果某个模块是 `nn.Linear`
- 就把它的权重初始化为均值默认、标准差为 `0.01` 的正态分布

### `nn.init.normal_`

这是 PyTorch 里的初始化函数。

注意结尾有下划线 `_`。

在 PyTorch 中，很多带下划线的方法表示：

```text
原地修改
```

也就是说，它直接修改 `m.weight` 本身，而不是返回一个新 tensor。

### `net.apply(init_weights)`

这句的意思是：

- 把 `init_weights` 应用到 `net` 里的每一个子模块上

这样：

- 每一个 `nn.Linear` 层的权重都会按你的规则初始化

## 9. 多层感知机和 Softmax 回归的关系

这是你现在最应该建立的“知识连接”。

### Softmax 回归

结构大致是：

```text
输入 -> 一个线性层 -> 输出 10 个类别分数
```

### 多层感知机

结构大致是：

```text
输入 -> 隐藏层 -> 激活函数 -> 输出层
```

### 两者最本质的差别

不是“类别数不同”，而是：

```text
MLP 多了隐藏层和非线性
```

所以可以把它理解成：

```text
MLP 是 Softmax 回归的增强版
```

## 10. 你现在最需要彻底弄懂的 5 个知识点

### 10.1 为什么隐藏层能增强模型能力

因为隐藏层让模型可以先学习中间表示，而不是直接从输入到输出一把映射。

### 10.2 为什么必须有激活函数

因为没有激活函数，多层线性层叠加仍然等价于一个线性层。

### 10.3 为什么这里不用手写 softmax

因为 `nn.CrossEntropyLoss` 通常直接接收输出层 logits，并在内部处理分类损失所需的变换。

### 10.4 为什么参数要初始化得比较小

因为初始值太大可能让训练不稳定，较小随机初值是常见做法。

### 10.5 为什么训练流程没变

尽管模型从单层变成了多层，但训练本质仍然是：

```text
前向传播 -> 计算损失 -> backward -> 参数更新
```

## 11. 你现在这个 notebook 里可以顺手注意的小点

### 变量名拼写

你写的是：

```python
num_hideens
```

通常更常见的是：

```python
num_hiddens
```

这不是功能性 bug，但长期来看建议尽量写规范一些，后面看自己代码会更舒服。

### `requires_grad=True` 和 `nn.Parameter`

你这里写成：

```python
nn.Parameter(torch.randn(..., requires_grad=True) * 0.01)
```

在逻辑上可以工作。

不过很多时候只要写成：

```python
nn.Parameter(torch.randn(...) * 0.01)
```

也可以，因为 `nn.Parameter` 本身就表示这是可训练参数。

## 13. 最后用最简单的话总结

多层感知机的核心，不是“层变多了”这么简单，而是：

```text
在线性模型中加入隐藏层，并通过激活函数引入非线性
```

你的 notebook 主线可以总结成：

```text
图片 -> 拉平 -> 第一层线性变换 -> ReLU -> 第二层线性变换 -> 交叉熵损失 -> 反向传播 -> SGD 更新参数
```

只要你把这条主线、每层张量形状、以及 `ReLU` 的作用吃透，这一章就算真正入门了。
