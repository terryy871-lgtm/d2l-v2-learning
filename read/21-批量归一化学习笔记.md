如果用一句话概括这一章：

```text
批量归一化的核心思想是：让中间层输入的数值分布更稳定，同时保留模型自己调整分布的能力
```

## 1. 先用人话理解为什么需要批量归一化

神经网络训练时，每一层的输入都来自前一层的输出。

当前面层的参数不断更新时，后面层看到的数据分布也会不断变化。

这会让训练变得不稳定：

```text
后面的层刚适应一种输入分布，前面的层一更新，分布又变了
```

批量归一化想做的事是：

```text
在层与层之间，把输入先调整到比较稳定的均值和方差范围
```

这样可以让训练更顺滑，允许使用更大的学习率，也常常有一定正则化效果。

## 2. 批量归一化的基本公式

对一个小批量输入 `X`，BatchNorm 大致做：

```text
X_hat = (X - mean) / sqrt(var + eps)
Y = gamma * X_hat + beta
```

这里每个符号的含义是：

- `mean`：当前批量的均值
- `var`：当前批量的方差
- `eps`：防止除以 0 的小常数
- `gamma`：可学习的缩放参数
- `beta`：可学习的偏移参数

前半部分是标准化。

后半部分是让模型自己决定：

```text
标准化之后，要不要再把数据拉伸或平移到更适合任务的位置
```

## 3. 为什么需要 `gamma` 和 `beta`

如果只做标准化，输出会被强行限制在某种固定分布附近。

这可能会削弱网络表达能力。

所以 BatchNorm 加了两个可学习参数：

```python
Y = gamma * X_hat + beta
```

它们的作用是：

- `gamma` 控制缩放
- `beta` 控制平移

这让模型可以在需要时恢复或调整原来的分布。

所以 BatchNorm 不是简单粗暴地把数据固定住，而是：

```text
先稳定数值分布，再把最终分布选择权交还给模型
```

## 4. 训练阶段和推理阶段为什么不同

你手写的函数里有这一段：

```python
if not torch.is_grad_enabled():
    X_hat = (X - moving_mean) / torch.sqrt(moving_var + eps)
else:
    ...
```

这说明 BatchNorm 在训练和推理时行为不同。

### 训练阶段

训练时可以使用当前 batch 的均值和方差：

```text
用当前小批量统计量来归一化
```

同时更新：

- `moving_mean`
- `moving_var`

### 推理阶段

推理时通常一次可能只输入一个样本，不能稳定估计 batch 统计量。

所以要使用训练过程中累计出来的移动平均：

```text
用 moving_mean 和 moving_var 来归一化
```

这就是为什么 BatchNorm 层在 `train()` 和 `eval()` 模式下行为不同。

## 5. 全连接层中怎么计算均值和方差

如果输入形状是二维：

```text
(batch_size, features)
```

代码里是：

```python
mean = X.mean(dim=0)
var = ((X - mean) ** 2).mean(dim=0)
```

这表示：

```text
对 batch 维度求均值和方差，每个特征单独归一化
```

也就是说，如果一个全连接层有 120 个输出特征，BatchNorm 会为这 120 个特征分别维护统计量。

## 6. 卷积层中怎么计算均值和方差

如果输入形状是四维：

```text
(batch_size, channels, height, width)
```

代码里是：

```python
mean = X.mean(dim=(0, 2, 3), keepdim=True)
var = ((X - mean) ** 2).mean(dim=(0, 2, 3), keepdim=True)
```

这表示：

```text
对 batch、高度、宽度三个维度一起求统计量，每个通道单独归一化
```

所以卷积层里的 BatchNorm 是按通道做的。

这很符合 CNN 的直觉：

```text
每个通道代表一种特征图，因此每个通道维护一套均值和方差
```

## 7. `BatchNorm` 类里哪些是参数，哪些不是参数

你手写类中有：

```python
self.gamma = nn.Parameter(torch.ones(shape))
self.beta = nn.Parameter(torch.zeros(shape))
self.moving_mean = torch.zeros(shape)
self.moving_var = torch.ones(shape)
```

这里：

### 可学习参数

- `gamma`
- `beta`

它们会参与梯度下降。

### 非学习状态

- `moving_mean`
- `moving_var`

它们不通过梯度学习，而是在训练过程中用移动平均更新。

这个区别很重要：

```text
BatchNorm 既有可训练参数，也有需要保存的运行统计量
```

## 8. 为什么要处理设备问题

类的 `forward` 里有：

```python
if self.moving_mean.device != X.device:
    self.moving_mean = self.moving_mean.to(X.device)
    self.moving_var = self.moving_var.to(X.device)
```

这是因为模型可能被移动到 GPU 上。

如果输入 `X` 在 GPU，而 `moving_mean` 还在 CPU，就会报设备不一致错误。

所以这里手动保证：

```text
运行统计量和输入张量在同一个设备上
```

官方 `nn.BatchNorm1d/2d` 会帮你处理这些细节。

## 9. BatchNorm 放在网络里的什么位置

你在 LeNet 变体里写了：

```python
nn.Conv2d(1, 6, kernel_size=5), BatchNorm(6, num_dims=4), nn.Sigmoid()
```

也就是：

```text
卷积/线性层 -> BatchNorm -> 激活函数
```

这是很常见的顺序。

它的直觉是：

```text
先把线性变换或卷积的输出标准化，再交给激活函数处理
```

现代网络中也经常看到类似顺序，尤其是：

```text
Conv -> BatchNorm -> ReLU
```

## 10. 手写实现和官方实现怎么对应

后面你又写了官方版本：

```python
nn.BatchNorm2d(6)
nn.BatchNorm1d(120)
```

它们分别对应：

### `nn.BatchNorm2d`

用于卷积层输出，输入通常是：

```text
(batch, channels, height, width)
```

### `nn.BatchNorm1d`

用于全连接层输出，输入通常是：

```text
(batch, features)
```

官方实现和你的手写实现思想一致，但更完整、更稳定，也能自动管理参数、状态和设备。

## 11. 这份 notebook 你最应该记住什么

学完这一章，最重要的是记住：

1. BatchNorm 用均值和方差稳定中间层分布
2. 训练时用当前 batch 统计量，推理时用移动平均统计量
3. `gamma` 和 `beta` 是可学习参数
4. 卷积层 BatchNorm 按通道统计，全连接层按特征统计
5. 官方的 `BatchNorm1d/2d` 是手写实现的工程化版本

如果最后只留一句话：

```text
批量归一化不是简单的数据预处理，而是插在网络内部、帮助深层模型更稳定训练的一种可学习层
```
