
## 1. 先用一句人话理解这两个问题

在神经网络训练中，参数更新依赖梯度。

如果梯度太小，会发生：

```text
参数几乎动不了
```

这叫：

```text
梯度消失
```

如果梯度太大，会发生：

```text
参数更新过猛，训练极不稳定
```

这叫：

```text
梯度爆炸
```

所以这两个问题本质上都在说：

```text
梯度的数值规模不合适
```

## 2. 为什么梯度大小这么重要

你前面已经学过：

```text
参数更新 = 旧参数 - 学习率 × 梯度
```

如果梯度特别小：

- 更新量也特别小
- 模型学得非常慢

如果梯度特别大：

- 更新量会非常大
- 参数可能来回震荡，甚至直接发散

所以训练能不能稳定推进，和梯度的数值范围关系非常大。

## 3. 梯度消失是什么

梯度消失通常指：

```text
在反向传播过程中，梯度不断连乘后越来越小，最后接近 0
```

这样会导致：

- 越靠前的层越难训练
- 深层网络前面几层几乎学不到东西

### 为什么会这样

因为反向传播本质上是链式法则。

如果每一层都乘上一个小于 1 的数，连续乘很多次以后，就会越来越接近 0。

这就是梯度消失的直觉来源。

## 4. 梯度爆炸是什么

梯度爆炸通常指：

```text
在反向传播或连乘过程中，梯度不断被放大，最后变得非常大
```

这样会导致：

- 参数更新幅度过大
- loss 震荡
- 数值不稳定
- 甚至出现 `nan`

### 为什么会这样

如果反向传播链条里每一步都乘上大于 1 的量，连续很多层之后，结果就会迅速膨胀。

## 5. 你的 notebook 在做什么

这份 notebook 虽然很短，但它用了两个非常典型的可视化实验，分别说明：

1. `sigmoid` 在大输入区间的梯度会变得很小，容易导致梯度消失
2. 随机矩阵连续相乘后，数值可能迅速变得极大，说明深层连乘可能导致梯度爆炸

所以它不是在训练完整模型，而是在帮你建立：

```text
为什么梯度会消失 / 爆炸的直觉
```

## 6. 按你的代码顺序详细讲

## 6.1 梯度消失实验

```python
%matplotlib inline
import torch
from d2l import torch as d2l
#梯度消失
x = torch.arange(-8.0,8.0,0.1,requires_grad=True)
y = torch.sigmoid(x)
y.backward(torch.ones_like(x))
d2l.plot(x.detach().numpy(), [y.detach().numpy(),x.grad.numpy()],legend=['sigmoid','gradient'],figsize=(4.5,2.5))
```

这一段是在演示：

```text
sigmoid 的梯度在两端会非常小
```

### `x`

```python
x = torch.arange(-8.0,8.0,0.1,requires_grad=True)
```

表示：

- 取一系列从 `-8` 到 `8` 的输入值

并且：

- 对这些输入开启梯度追踪

### `y = torch.sigmoid(x)`

这一步是计算 sigmoid 函数值。

sigmoid 的公式是：

```text
sigmoid(x) = 1 / (1 + e^(-x))
```

它的输出总在：

```text
0 到 1 之间
```

### 为什么 sigmoid 容易导致梯度消失

当 `x` 很大时：

- sigmoid(x) 接近 1

当 `x` 很小时：

- sigmoid(x) 接近 0

而在这两种情况下，sigmoid 的斜率都非常小。

这意味着：

```text
梯度会接近 0
```

### `y.backward(torch.ones_like(x))`

因为 `y` 不是一个标量，而是一整个向量，所以这里要显式传入：

```python
torch.ones_like(x)
```

这表示：

- 对每个输出分量都以权重 1 参与反向传播

最终 `x.grad` 会保存：

```text
sigmoid 对 x 的梯度
```

### `d2l.plot(...)`

最后画出了两条曲线：

1. sigmoid 曲线
2. sigmoid 梯度曲线

### 你应该从图上看到什么

你通常会看到：

- sigmoid 在中间区域变化比较明显
- 但在左右两端逐渐变平
- 对应梯度在两端接近 0

这就是梯度消失的直观图像。

### 这说明什么

如果深层网络里反复使用容易饱和的激活函数，比如 sigmoid，那么：

- 前面层接收到的梯度可能会越来越小
- 最后导致前面层基本学不到东西

## 6.2 梯度爆炸实验

```python
#梯度爆炸
M = torch.normal(0,1,size=(4,4))
print('一个矩阵 \\n',M)
for i in range(100):
    M = torch.mm(M,torch.normal(0, 1, size=(4, 4)))
print('乘以100个矩阵后\\n', M)
```

这一段是在用一个非常直接的方式说明：

```text
连续矩阵相乘后，数值可能会爆炸
```

### 初始矩阵 `M`

```python
M = torch.normal(0,1,size=(4,4))
```

表示：

- 先随机生成一个 `4x4` 矩阵

### 连续相乘 100 次

```python
for i in range(100):
    M = torch.mm(M,torch.normal(0, 1, size=(4, 4)))
```

这一步就是不断把矩阵乘上新的随机矩阵。

### 为什么这样能说明梯度爆炸

因为：

反向传播本质上也会涉及很多雅可比矩阵/导数项的连乘。

如果这些连乘的结果不断放大，就会出现：

```text
梯度爆炸
```

### 你通常会看到什么

输出的矩阵元素可能会：

- 非常大
- 数值乱飞
- 甚至在更极端情况下出现溢出

这就是梯度爆炸的直观类比。

## 7. 这一章真正要你建立的直觉

这章不是让你背定义，而是让你明白：

```text
深层网络训练时，梯度本身的数值稳定性就是一个问题
```

也就是说，哪怕：

- 模型结构对
- loss 定义对
- optimizer 也对

如果梯度本身传不过去，或者大到失控，训练照样会失败。

## 8. 为什么深层网络更容易遇到这两个问题

因为深层网络的反向传播要经过很多层。

而每一层都会带来：

- 导数项
- 权重矩阵
- 连乘操作

如果这些乘积长期：

- 小于 1
- 或大于 1

重复很多次之后，就很容易分别导致：

- 梯度消失
- 梯度爆炸

所以：

```text
网络越深，这类问题通常越明显
```

## 9. 为什么这章会放在多层感知机后面

因为你现在已经开始接触：

- 多层网络
- 更复杂的训练结构

一旦网络变深，训练就不再只是“照前面的模板写”这么简单，还要考虑：

```text

```

- 这里开始学“网络为什么有时训练不好”

## 10. 这章和激活函数的关系

你前面学过 ReLU，现在这章其实也在暗示一个重要事实：

```text
激活函数的选择会影响梯度传播
```

### sigmoid 的问题

sigmoid 在两端容易饱和：

- 接近 0
- 接近 1

一旦饱和，梯度就小。

这就是它容易造成梯度消失的原因之一。

### 为什么后来 ReLU 更流行

因为相较于 sigmoid，ReLU 在正区间梯度更稳定，不那么容易饱和。

所以它在深层网络里通常更好训练。

这也是你前面学 ReLU 时，后面又补这一章的原因之一。

## 11. 遇到梯度消失/爆炸时，常见的解决思路

这份 notebook 还没正式展开这些方法，但你现在可以先知道一些方向：

### 对付梯度消失

- 使用更合适的激活函数，例如 ReLU
- 合理初始化参数
- 使用归一化方法
- 改善网络结构

### 对付梯度爆炸

- 减小学习率
- 合理初始化参数
- 使用梯度裁剪（gradient clipping）
- 改进网络结构

这些内容你后面继续学深度网络、RNN、Transformer 时会经常遇到。

## 12. 你现在最应该彻底弄懂的 5 个点

### 12.1 梯度消失是什么意思

不是“没有梯度”，而是：

```text
梯度小到几乎传不回去
```

### 12.2 梯度爆炸是什么意思

不是“梯度多一点”，而是：

```text
梯度大到训练不稳定甚至发散
```

### 12.3 sigmoid 为什么容易导致梯度消失

因为在两端饱和时斜率很小。

### 12.4 为什么矩阵连续相乘会带来爆炸风险

因为连乘会不断放大某些方向上的数值。

### 12.5 为什么这两个问题在深层网络里更明显

因为深层网络的反向传播本质上就是多层连乘。

```text
神经网络训练时，梯度既不能太小，也不能太大
```

- 学崩掉
