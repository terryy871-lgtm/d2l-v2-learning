## 1. 先用一句人话理解 LeNet 在做什么

前面你已经分别学过：

- 卷积：提取局部模式
- 填充和步幅：控制特征图大小
- 多通道：扩展特征维度
- 池化：压缩局部信息

LeNet 这一章真正做的事，就是把这些零散组件第一次组装成一个完整可训练的图像分类网络。

它的整体流程可以理解成：

```text
输入图片 -> 提取边缘/纹理等局部特征 -> 逐步压缩空间尺寸 -> 展平 -> 分类
```

所以这一章最重要的，不只是记住某个经典结构，而是看懂：

```text
一个卷积神经网络是怎么从原始图像一步一步走到最终类别预测的
```

## 2. 你的网络结构长什么样

notebook 里定义的是：

```python
net = nn.Sequential(
    nn.Conv2d(1, 6, kernel_size=5, padding=2), nn.Sigmoid(),
    nn.AvgPool2d(kernel_size=2, stride=2),
    nn.Conv2d(6, 16, kernel_size=5), nn.Sigmoid(),
    nn.AvgPool2d(kernel_size=2, stride=2),
    nn.Flatten(),
    nn.Linear(16 * 5 * 5, 120), nn.Sigmoid(),
    nn.Linear(120, 84), nn.Sigmoid(),
    nn.Linear(84, 10))
```

把它翻译成人话就是：

1. 第一层卷积，从 1 个通道提取成 6 个通道
2. 做一次激活
3. 做一次平均池化，缩小特征图
4. 第二层卷积，从 6 个通道提取成 16 个通道
5. 再激活、再池化
6. 把三维特征图拉平成一维向量
7. 交给全连接层做最终分类

这其实就是很典型的 CNN 模式：

```text
卷积部分负责提特征，全连接部分负责做决策
```

## 3. 为什么第一层卷积后输出还是 `28 x 28`

第一层是：

```python
nn.Conv2d(1, 6, kernel_size=5, padding=2)
```

输入是 `28 x 28` 的灰度图。

因为用了 `5 x 5` 卷积核和 `padding=2`，所以高宽会保持不变。

于是输出变成：

```text
6 x 28 x 28
```

这里的 `6` 代表：

```text
这一层学了 6 组不同的卷积核，因此得到 6 张不同的特征图
```

## 4. 为什么池化后尺寸会减半

接下来是：

```python
nn.AvgPool2d(kernel_size=2, stride=2)
```

这表示用 `2 x 2` 的窗口做平均池化，而且每次移动 2 格。

结果就是：

```text
28 x 28 -> 14 x 14
```

通道数不变，所以变成：

```text
6 x 14 x 14
```

这一步说明池化的主要作用就是：

```text
压缩空间尺寸，同时保留局部特征的概括信息
```

## 5. 第二个卷积块在干什么

第二层卷积是：

```python
nn.Conv2d(6, 16, kernel_size=5)
```

这里没有填充，所以特征图会缩小。

输入是 `6 x 14 x 14`，卷积后变成：

```text
16 x 10 x 10
```

然后再经过一次 `2 x 2` 平均池化，变成：

```text
16 x 5 x 5
```

这个变化非常值得体会：

- 通道数在增加：`1 -> 6 -> 16`
- 空间尺寸在减小：`28 -> 14 -> 10 -> 5`

这体现了 CNN 很经典的设计思想：

```text
越往后，空间分辨率越低，但特征表示越丰富
```

## 6. 为什么要 `Flatten`

经过卷积和池化以后，输出还是三维特征图：

```text
16 x 5 x 5
```

但全连接层要求输入是一维向量，所以需要：

```python
nn.Flatten()
```

这一步做的只是形状变换：

```text
16 x 5 x 5 -> 400
```

这里的 `400` 就是：

```text
16 * 5 * 5
```

它相当于把前面提取到的空间特征全部摊平成一个长向量，交给后面的分类器。

## 7. 后面的全连接层在做什么

后面三层线性层是：

```python
400 -> 120 -> 84 -> 10
```

它们的角色可以理解成：

### 前面卷积部分

```text
负责把图片变成有判别力的特征表示
```

### 后面全连接部分

```text
负责根据这些特征做最终分类
```

最后输出的 `10` 对应的就是 `Fashion-MNIST` 的 10 个类别。

## 8. 你打印每层输出形状这一步特别重要

notebook 里有这样一段：

```python
X = torch.rand(size=(1, 1, 28, 28), dtype=torch.float32)
for layer in net:
    X = layer(X)
    print(layer.__class__.__name__, 'output shape:\t', X.shape)
```

这一步非常适合入门，因为它让你不只是“看到定义”，而是真正看到：

```text
数据经过每一层之后，形状是怎么变化的
```

卷积网络初学最容易乱的地方，就是：

- 高宽什么时候变
- 通道什么时候变
- 为什么能接到线性层

这段代码正好把这些关系全部串清楚了。

## 10. 为什么 LeNet 虽老但很适合入门

LeNet 虽然是很早期的网络，但它特别适合入门，因为它清楚展示了 CNN 的基本骨架：

1. 卷积提特征
2. 池化降采样
3. 多层堆叠
4. 展平
5. 全连接分类

很多后面的卷积网络虽然更深、更强，但整体思路还是从这个框架发展出来的。

所以学 LeNet 的价值不在于它今天是不是最强，而在于它能帮你建立：

```text
卷积神经网络整体工作流程的第一性理解
```
