## 1. 先用人话理解“深层”

前面你学的 RNN、GRU、LSTM，大多可以先理解成一层循环层。

一层循环层已经会沿着时间传递隐藏状态。

深层 RNN 则是在这个基础上继续堆叠：

```text
第一层 RNN 的输出 -> 第二层 RNN 的输入 -> 更高层表示
```

所以它有两个方向：

### 时间方向

```text
t1 -> t2 -> t3 -> ...
```

### 层方向

```text
第 1 层 -> 第 2 层 -> 第 3 层
```

这就是深层循环网络的直觉。

## 3. `num_layers=2` 表示什么

核心代码是：

```python
vocab_size, num_hiddens, num_layers = len(vocab), 256, 2
lstm_layer = nn.LSTM(num_inputs, num_hiddens, num_layers)
```

这里：

- `num_inputs = vocab_size`
- `num_hiddens = 256`
- `num_layers = 2`

`num_layers=2` 表示堆叠两个 LSTM 层。

第一层 LSTM 读取输入序列，输出隐藏表示。

第二层 LSTM 再读取第一层的输出，生成更高层的序列表示。

## 4. 深层 RNN 比单层 RNN 强在哪里

单层 RNN 只能在一层隐藏状态中压缩所有信息。

深层 RNN 可以逐层抽象：

- 低层捕捉局部、短期模式
- 高层组合更抽象、更长程的模式

在语言模型里，低层可能更关注字符拼写模式，高层可能更关注更长的上下文结构。

当然这只是直觉，实际表示由训练自动学习。

## 5. 深层 RNN 的代价是什么

堆叠更多层会带来：

- 参数更多
- 计算更慢
- 更容易过拟合
- 梯度传播路径更长
- 调参更敏感

所以深层不是越多越好。

这份 notebook 用 2 层，是一个比较适合教学和实验的设置。

## 6. 为什么还要梯度裁剪

训练器里使用了：

```python
gradient_clip_val=1
```

RNN 本来就容易出现梯度爆炸。

深层 RNN 的计算路径更长，更需要控制梯度规模。

梯度裁剪的作用是：

```text
当梯度范数过大时，把它按比例缩小到阈值以内
```

这样训练更稳定。
