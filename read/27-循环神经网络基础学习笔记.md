## 1. 为什么普通神经网络不够处理序列

普通 MLP 处理输入时，通常假设每个样本独立。

但序列数据不一样。

比如一句话：

```text
the time traveller
```

理解后面的词，需要记住前面出现了什么。

所以模型需要某种“记忆”。

RNN 的隐藏状态就是这种记忆。

## 2. RNN 的基本更新形式

一个简单 RNN 的隐藏状态可以写成：

```text
H_t = f(X_t W_xh + H_{t-1} W_hh + b_h)
```

其中：

- `X_t`：当前时间步输入
- `H_{t-1}`：上一时间步隐藏状态
- `W_xh`：输入到隐藏状态的权重
- `W_hh`：隐藏状态到隐藏状态的权重
- `H_t`：当前时间步新的隐藏状态

这说明 RNN 的每一步都由两部分共同决定：

```text
当前看到什么 + 之前记住什么
```

## 3. notebook 第一段代码在算什么

代码中：

```python
X, W_xh = torch.normal(0, 1, (3, 1)), torch.normal(0, 1, (1, 4))
H, W_hh = torch.normal(0, 1, (3, 4)), torch.normal(0, 1, (4, 4))
torch.matmul(X, W_xh) + torch.matmul(H, W_hh)
```

这里有两个计算：

1. `torch.matmul(X, W_xh)`：当前输入对新隐藏状态的贡献
2. `torch.matmul(H, W_hh)`：旧隐藏状态对新隐藏状态的贡献

把它们相加，就是新隐藏状态激活前的值。

这里暂时没有加偏置和激活函数，是为了突出矩阵计算关系。

## 4. 为什么第二段代码等价

第二段代码是：

```python
torch.matmul(torch.cat((X, H), 1), torch.cat((W_xh, W_hh), 0))
```

它做了两次拼接：

### 拼接输入

```text
[X, H]
```

把当前输入和隐藏状态在特征维度拼起来。

### 拼接权重

```text
[W_xh; W_hh]
```

把两个权重矩阵在行方向拼起来。

这样一次矩阵乘法就等价于：

```text
X W_xh + H W_hh
```

这说明很多框架内部可以把多个线性变换合并成一次更大的矩阵乘法，提高实现效率。

## 5. 隐藏状态到底“隐藏”在哪里

隐藏状态不是标签，也不是直接输出。

它是模型内部保存的信息。

在序列每个时间步，隐藏状态都会更新：

```text
H_1 -> H_2 -> H_3 -> ...
```

它像一份滚动摘要：

```text
到当前时间步为止，模型认为重要的历史信息
```

这就是 RNN 能处理序列的根本原因。

## 6. RNN 和 MLP 的关键区别

### MLP

```text
每个样本独立处理，没有跨时间状态
```

### RNN

```text
每个时间步都会接收上一时间步的隐藏状态
```

所以 RNN 的参数在所有时间步共享。

同一组 `W_xh` 和 `W_hh` 会反复用于整个序列。

这让模型能处理不同长度的序列。

1. RNN 用隐藏状态保存历史信息
2. 新隐藏状态由当前输入和旧隐藏状态共同决定
3. `XW_xh + HW_hh` 可以改写成拼接后的一次矩阵乘法
4. RNN 的参数在时间维度上共享
5. 隐藏状态是后面语言模型训练的核心
