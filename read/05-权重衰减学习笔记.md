## 1. 先用一句人话理解权重衰减

前一章你已经学了：

- 欠拟合
- 过拟合

你会发现一个现实问题：

```text
模型一旦太复杂，就容易把训练集记得太死
```

那怎么办？

一种很经典的办法就是：

```text
在训练时惩罚“太大的权重”
```

也就是说，模型虽然仍然可以学习，但我们不希望它把参数调得特别夸张。

这就是权重衰减的基本思想。

## 2. 权重衰减和 L2 正则化是什么关系

在这类教程里，这两个词几乎总是放在一起讲。

### L2 正则化

L2 正则化做的事情是：

在原来的损失函数后面再加一项：

```text
loss = 原始损失 + λ * ||w||² / 2
```

这里：

- `w`：模型权重
- `||w||²`：权重平方和
- `λ`：惩罚强度

### 权重衰减

权重衰减通常可以看成：

```text
L2 正则化在优化过程中的一种表现形式
```

从直觉上说，它会让参数在每次更新时都稍微“往 0 缩一点”。

所以这两个词在很多入门阶段的材料里，你可以先近似理解成同一类方法。

## 3. 为什么要惩罚大的权重

这是这章最关键的直觉。

如果一个模型某些参数特别大，往往意味着：

- 模型对输入中的某些细节过于敏感
- 更容易把噪声也当成规律学进去

而我们更希望模型学到的是：

```text
稳定、平滑、泛化能力更强的规律
```

所以通过惩罚大权重，可以让模型更“克制”一些。

### 你可以把它理解成

不加正则化时，模型可能会想：

```text
只要能把训练集拟合得很好，参数多大都无所谓
```

加了 L2 正则化以后，模型会变成：

```text
我不仅要拟合训练集，还要尽量别把参数搞得太离谱
```

## 6.3 初始化模型参数

```python
def init_params():
    w = torch.normal(0,1,size=(num_inputs,1),requires_grad= True)
    b = torch.zeros(1,requires_grad= True)
    return [w,b]
```

这一步是在手动初始化参数。

### `w`

这里的权重：

```python
w.shape = (200, 1)
```

因为输入维度是 200，输出是 1。

### 为什么这里初始化得比较大

你这里用了：

```python
torch.normal(0,1,...)
```

这意味着初始权重方差不小。

这种设定更容易让你观察到：

- 如果不加约束，权重可能会变得比较大
- 加了权重衰减以后，权重会被压下来

### `requires_grad=True`

表示：

- 这些参数后面要参与梯度计算

## 6.4 定义 L2 范数惩罚

```python
def l2_penalty(w):
    return torch.sum(w.pow(2)) / 2
```

这是这份 notebook 的核心函数之一。

### 它在计算什么

它计算的是：

```text
||w||² / 2
```

也就是：

```text
所有权重平方后求和，再除以 2
```

### 为什么是平方和

因为我们希望：

- 权重越大，惩罚越大
- 而且惩罚应该始终是正的

平方正好满足这个要求。

### 为什么除以 2

主要是数学推导更方便。

因为后面求导时：

```text
d(w²/2)/dw = w
```

形式更整洁。

所以：

```python
return torch.sum(w.pow(2)) / 2
```

是一个非常标准的 L2 正则项写法。

## 6.5 手写训练函数

```python
def train(lambd):
    w,b = init_params()
    net, loss = lambda X: d2l.linreg(X,w,b), d2l.squared_loss
    num_epochs, lr = 100, 0.003
    animator = d2l.Animator(xlabel='epochs', ylabel='loss', yscale='log',
                            xlim=[5, num_epochs], legend=['train', 'test'])
    for epoch in range(num_epochs):
        for X, y in train_iter:
            # 添加L2范数惩罚项
            l = loss(net(X), y) + lambd * l2_penalty(w)
            l.sum().backward()
            d2l.sgd([w, b], lr, batch_size)
        if(epoch + 1)%5==0:
            animator.add(epoch + 1, (d2l.evaluate_loss(net, train_iter, loss),d2l.evaluate_loss(net, test_iter, loss)))
    print('w的l2范数：', torch.norm(w).item())
```

这一段是整份 notebook 的主干。

### 最关键的一行

```python
l = loss(net(X), y) + lambd * l2_penalty(w)
```

这句就是“权重衰减/L2 正则化”真正加进训练的地方。

你一定要把它看懂。

原本的损失是：

```text
原始损失 = 预测误差
```

现在变成：

```text
总损失 = 预测误差 + λ * 权重惩罚
```

这意味着模型训练时，优化目标不再只是：

```text
把预测误差降到最低
```

而是：

```text
既要拟合数据，又要尽量让权重别太大
```

### `lambd` 是什么

这里的 `lambd` 就是：

```text
正则化强度
```

它控制：

- 惩罚项有多强

如果：

```text
lambd = 0
```

那就相当于：

```text
完全不加正则化
```

如果：

```text
lambd` 比较大
```

那模型就会更强烈地压制大权重。

### `net`

```python
net = lambda X: d2l.linreg(X,w,b)
```

这里本质上还是线性回归模型。

这说明这一章研究的重点不是模型结构，而是：

```text
在同一个模型上，加不加正则化会带来什么差异
```

### `loss = d2l.squared_loss`

这里仍然是平方损失，因为任务还是回归。

### `l.sum().backward()`

这一步很关键。

因为现在参与求导的不只是预测误差，还包括：

```text
lambd * l2_penalty(w)
```

所以梯度里自然也会包含：

```text
“把权重往小了拉”的那部分力量
```

这就是为什么权重衰减最终会让参数变小。

### `d2l.sgd([w, b], lr, batch_size)`

更新参数时：

- `w` 会同时受到数据误差和 L2 惩罚的影响
- `b` 没有被加进惩罚项，所以只根据普通损失更新

这一点也很重要：

```text
L2 正则化通常主要惩罚权重，不强调惩罚偏置
```

### `animator`

这里仍然是在画：

- train loss
- test loss

目的是观察：

```text
加正则化前后，训练集和测试集的损失曲线有什么变化
```

### 最后打印 `w` 的 L2 范数

```python
print('w的l2范数：', torch.norm(w).item())
```

这一步非常直观。

它直接告诉你：

```text
最后学到的权重整体有多大
```

如果加了权重衰减，这个值通常会更小。


- 训练损失可能不如不加正则化时那么低

这说明：

```text

```

这正是权重衰减的价值。

## 7. 简洁实现部分

## 7.1 定义简洁训练函数

```python
def train_concise(wd):
    net = nn.Sequential(nn.Linear(num_inputs,1))
    for param in net.parameters():
        param.data.normal_()
    loss = nn.MSELoss(reduction='none')
    num_epochs, lr = 100, 0.003
    trainer = torch.optim.SGD([
        {"params":net[0].weight,'weight_decay': wd},
        {"params":net[0].bias}], lr=lr)
    animator = d2l.Animator(xlabel='epochs', ylabel='loss', yscale='log',xlim=[5, num_epochs], legend=['train', 'test'])
    for epoch in range(num_epochs):
        for X, y in train_iter:
            trainer.zero_grad()
            l = loss(net(X), y)
            l.mean().backward()
            trainer.step()
        if(epoch + 1)%5==0:
            animator.add(epoch + 1, (d2l.evaluate_loss(net, train_iter, loss),d2l.evaluate_loss(net, test_iter, loss)))
        print('w的L2范数：', net[0].weight.norm().item())
```

这部分是在用 PyTorch 官方方式实现同样的事情。

### `net = nn.Sequential(nn.Linear(num_inputs,1))`

这里定义的是一个标准线性回归模型。

和前半部分本质相同。

### 初始化参数

```python
for param in net.parameters():
    param.data.normal_()
```

作用是：

- 把模型参数随机初始化

### 真正的重点：`weight_decay`

```python
trainer = torch.optim.SGD([
    {"params":net[0].weight,'weight_decay': wd},
    {"params":net[0].bias}], lr=lr)
```

这是简洁实现里最关键的一行。

你要特别注意这里的结构。

它不是简单写：

```python
torch.optim.SGD(net.parameters(), lr=lr, weight_decay=wd)
```

而是写成了参数组：

```python
[
    {"params": net[0].weight, "weight_decay": wd},
    {"params": net[0].bias}
]
```

### 为什么这么写

因为我们希望：

- 对权重加权重衰减
- 对偏置不加权重衰减

也就是说：

```text
weight 被正则化
bias 不被正则化
```

这在实践里是很常见的做法。

### 训练循环

```python
trainer.zero_grad()
l = loss(net(X), y)
l.mean().backward()
trainer.step()
```

这一套就是 PyTorch 的标准训练流程。

这里你会发现：

```text
代码里已经不需要手动把 l2_penalty(w) 加到损失函数里了
```

因为优化器已经通过：

```python
weight_decay = wd
```

自动帮你处理了。

所以：

```text
前半部分是手写原理，后半部分是框架封装
```

## 8. 这一章最核心的理解

你一定要抓住这句话：

```text
权重衰减不是让模型“学不会”，而是让模型“别学得太夸张”
```

这很重要。

因为初学者很容易误以为：

```text
加正则化是不是就是故意让模型变差？
```

不是。

它的真正目的在于：

```text
牺牲一点训练集上的极致拟合，换来更好的泛化能力
```

## 9. 你现在最应该彻底弄懂的 5 个点

### 9.1 为什么这个实验场景容易过拟合

因为：

- 输入维度 200
- 训练样本只有 20

这就是典型的高维小样本问题。

### 9.2 L2 惩罚项到底加在哪里

就在这里：

```python
l = loss(net(X), y) + lambd * l2_penalty(w)
```

### 9.3 为什么它会让权重变小

因为总损失里加入了“惩罚大权重”的项，所以梯度会把参数往更小方向推。

### 9.4 为什么通常只惩罚 weight，不强调惩罚 bias

因为权重更直接决定模型复杂度，偏置通常不是主要的复杂度来源。

### 9.5 为什么加正则化后训练损失可能反而更高

因为模型被限制得更克制，不再一味追求把训练集拟合到极致。

但这不一定是坏事，反而可能说明：

```text
泛化能力更好
```
