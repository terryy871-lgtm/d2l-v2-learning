## 1. 为什么要学简洁实现

从零实现 RNN 能帮助你理解原理。

但实际写项目时，通常不会手写每个权重矩阵和时间步循环。

我们会使用框架提供的：

```python
nn.RNN
```

它内部已经实现了：

- 隐藏状态更新
- 时间步循环
- 参数管理
- 多层 RNN 支持

这一章的目的就是把你从“理解原理”带到“会用框架”。

## 3. `nn.RNN` 的输入是什么

代码中：

```python
rnn_layer = nn.RNN(len(vocab), num_hiddens)
```

这里：

- `len(vocab)` 是输入维度，也就是独热向量长度
- `num_hiddens` 是隐藏单元数量

PyTorch 的 RNN 默认输入形状是：

```text
(num_steps, batch_size, input_size)
```

也就是：

```text
时间步在第一维
```

这和从零实现中手动转置后的形状一致。

## 4. 隐藏状态形状怎么看

代码中：

```python
state = torch.zeros((1, batch_size, num_hiddens))
```

这里第一维是层数。

对单层单向 RNN 来说，隐藏状态形状是：

```text
(1, batch_size, num_hiddens)
```

如果是多层 RNN，第一维会变成层数。

如果是双向 RNN，还要乘以方向数。

所以隐藏状态第一维不是 batch，而是：

```text
层数 x 方向数
```

## 5. RNN 层输出是什么形状

测试代码：

```python
X = torch.rand(size=(num_steps, batch_size, len(vocab)))
Y, state_new = rnn_layer(X, state)
```

其中：

- `Y` 包含每个时间步的隐藏状态输出
- `state_new` 是最后一个时间步的隐藏状态

`Y` 的形状通常是：

```text
(num_steps, batch_size, num_hiddens)
```

`state_new` 的形状是：

```text
(1, batch_size, num_hiddens)
```

要注意：

```text
RNN 层本身输出的是隐藏特征，不是词表概率
```

所以还需要线性层。

## 6. 为什么要写 `RNNModel`

`nn.RNN` 只负责循环层。

语言模型还需要把隐藏状态映射到词表大小的输出。

所以代码里定义了：

```python
self.linear = nn.Linear(self.num_hiddens, self.vocab_size)
```

整体流程是：

1. 输入字符索引
2. 转成独热向量
3. 送入 `nn.RNN`
4. 得到每个时间步隐藏状态
5. 线性层输出词表大小的预测分数

这和从零实现完全对应，只是 RNN 内部计算交给了 PyTorch。

## 7. `forward` 里为什么要 reshape

代码中：

```python
output = self.linear(Y.reshape((-1, Y.shape[-1])))
```

`Y` 原本形状是：

```text
(num_steps, batch_size, num_hiddens)
```

线性层希望处理二维输入：

```text
(样本数, 特征数)
```

所以把前两维合并：

```text
(num_steps * batch_size, num_hiddens)
```

线性层输出后得到：

```text
(num_steps * batch_size, vocab_size)
```

这样就能和展平后的标签计算交叉熵损失。

## 8. 简洁实现和从零实现的对应关系

### 从零实现

```text
自己写 W_xh、W_hh、循环、隐藏状态更新
```

### 简洁实现

```text
nn.RNN 负责循环层，自己只写输入转换和输出层
```

两者本质一样。

区别只是：

```text
一个用于理解原理，一个用于实际开发
```

## 9. 训练器做了什么

最后使用：

```python
trainer = d2l.Trainer(max_epochs=500, gradient_clip_val=1, num_gpus=1)
trainer.fit(model, data)
```

这里的训练器封装了：

- epoch 循环
- 前向传播
- 反向传播
- 参数更新
- 梯度裁剪
- 设备管理

这让 notebook 更短，但你要能知道背后仍然是前面那套训练逻辑。

## 10. 这份 notebook 你最应该记住什么

学完这一章，最重要的是记住：

1. `nn.RNN` 替我们实现了循环计算和参数管理
2. RNN 输入默认是 `(时间步, 批量, 输入维度)`
3. RNN 输出还不是词表预测，需要接线性层
4. `Y.reshape((-1, Y.shape[-1]))` 是为了对每个时间步做分类
5. 简洁实现和从零实现逻辑一致，只是抽象层级更高
