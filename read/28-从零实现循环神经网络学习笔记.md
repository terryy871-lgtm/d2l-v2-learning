## 1. 这份 notebook 在做什么

前面你已经知道，语言模型要根据前面的字符预测下一个字符。

这一章更进一步，不再只讲数据，而是从零实现模型。

完整流程是：

1. 读取《时间机器》文本
2. 构建字符级语料
3. 把字符索引转成独热向量
4. 初始化 RNN 参数
5. 手写隐藏状态更新
6. 训练语言模型
7. 用模型生成文本

这章代码多，但主线其实很清楚：

```text
输入字符序列 -> RNN 更新隐藏状态 -> 输出下一个字符概率
```

## 2. 为什么要用独热编码

字符先被转换成索引，比如：

```text
"t" -> 5
```

但索引本身只是编号，不能直接表达类别。

所以代码里用：

```python
F.one_hot(...)
```

把索引变成独热向量。

如果词表大小是 28，那么字符 `"t"` 会变成长度为 28 的向量，其中只有一个位置是 1，其余都是 0。

这让 RNN 的输入可以参与矩阵乘法。

## 3. RNN 参数有哪些

`get_params` 中初始化了：

```python
W_xh, W_hh, b_h, W_hq, b_q
```

它们分别表示：

- `W_xh`：输入到隐藏状态
- `W_hh`：上一隐藏状态到当前隐藏状态
- `b_h`：隐藏层偏置
- `W_hq`：隐藏状态到输出
- `b_q`：输出层偏置

可以把 RNN 分成两部分：

### 隐藏状态更新

```text
H_t = tanh(X_t W_xh + H_{t-1} W_hh + b_h)
```

### 输出预测

```text
Y_t = H_t W_hq + b_q
```

每个时间步都会重复这两步。

## 4. 隐藏状态初始化

代码中：

```python
def init_rnn_state(batch_size, num_hiddens, device):
    return (torch.zeros((batch_size, num_hiddens), device=device), )
```

一开始没有历史信息，所以隐藏状态初始化为 0。

注意它返回的是一个元组。

这样做是为了和后面更复杂的模型兼容，比如 LSTM 会有多个状态。

## 5. `rnn` 函数到底在循环什么

核心代码是：

```python
for X in inputs:
    H = torch.tanh(torch.mm(X, W_xh) + torch.mm(H, W_hh) + b_h)
    Y = torch.mm(H, W_hq) + b_q
    outputs.append(Y)
```

`inputs` 的形状是：

```text
(时间步数量, 批量大小, 词表大小)
```

循环中的每个 `X` 是一个时间步的输入。

每一步都：

1. 用当前输入和旧隐藏状态计算新隐藏状态
2. 用新隐藏状态计算输出
3. 保存输出

最后把所有时间步的输出拼起来。

这就是 RNN 的本质。

## 6. `RNNModelScratch` 封装了什么

这个类把几个组件包起来：

- 参数初始化
- 状态初始化
- 前向计算函数
- 独热编码转换

它的 `__call__` 中：

```python
X = F.one_hot(X.T, self.vocab_size).type(torch.float32)
```

这里 `X.T` 很关键。

训练数据通常是：

```text
(batch_size, num_steps)
```

但 RNN 前向循环希望时间步在第一维：

```text
(num_steps, batch_size)
```

所以要转置。

## 7. 文本生成为什么需要预热

`predict_ch8` 中有一段：

```python
for y in prefix[1:]:
    _, state = net(get_input(), state)
    outputs.append(vocab[y])
```

这叫预热。

如果前缀是：

```text
time traveller
```

模型先把这些已知字符一个个喂进去，更新隐藏状态。

这样模型的状态就包含了前缀上下文。

之后再开始预测新字符。

否则模型只看第一个字符，生成会更不稳定。

## 8. 为什么需要梯度裁剪

RNN 会在时间维度上反复展开。

如果序列较长，反向传播时梯度可能不断放大，出现梯度爆炸。

代码中：

```python
grad_clipping(net, 1)
```

会把梯度范数限制在阈值以内。

这不是改变模型结构，而是让训练更稳定。

可以理解成：

```text
梯度太大时，把它按比例缩回来
```

## 9. 为什么训练时要 detach 隐藏状态

顺序分区时，隐藏状态可以从上一个 batch 延续到下一个 batch。

但如果不做处理，计算图会一直连下去。

这样会导致：

- 内存越来越大
- 反向传播跨越太长历史
- 训练变慢甚至崩掉

所以代码中会对隐藏状态做：

```python
s.detach_()
```

意思是：

```text
保留隐藏状态的数值，但切断它和旧计算图的梯度连接
```

这是 RNN 训练里非常重要的细节。

## 10. 困惑度是什么

训练时打印的是 perplexity，中文常叫困惑度。

它可以理解成语言模型预测下一个词元时的“不确定程度”。

困惑度越低，说明模型越不困惑，预测越好。

如果词表大小是 28，完全随机猜的困惑度大概会接近 28。

训练后困惑度下降，说明模型学到了字符序列规律。

## 11. 这份 notebook 你最应该记住什么

学完这一章，最重要的是记住：

1. 字符索引要先转成独热向量
2. RNN 的隐藏状态会沿时间步传递
3. 同一组参数在所有时间步共享
4. 生成文本前要用前缀预热隐藏状态
5. 梯度裁剪能缓解梯度爆炸
6. `detach` 用来截断隐藏状态背后的计算图

如果最后只留一句话：

```text
从零实现 RNN 的价值，是让你亲手看到隐藏状态、时间步循环、梯度裁剪和文本生成是怎么连在一起的
```
