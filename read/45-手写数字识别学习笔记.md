## 2. 数据是怎么读进来的

你先写了：

```python
from dataset.mnist import load_mnist
```

然后在 `get_data()` 里：

```python
(x_train, t_train), (x_test, t_test) = load_mnist(
    normalize=True, flatten=True, one_hot_label=False
)
return x_test, t_test
```

这里有三个很关键的设置：

### `normalize=True`

表示把像素值做归一化处理。

这样输入数值范围更合适，网络更容易稳定工作。

### `flatten=True`

表示把原始的二维图像拉平成一维向量。

MNIST 原始图片是 `28 x 28`，拉平后就是：

```text
784 维向量
```

这说明这里用的不是卷积网络，而是：

```text
全连接前馈神经网络
```

### `one_hot_label=False`

表示标签保留成普通类别编号，比如 `0~9`，而不是 one-hot 向量。

## 4. 前向传播函数 `predict()` 到底在干什么

核心函数是：

```python
def predict(network, x):
    W1, W2, W3 = network['W1'], network['W2'], network['W3']
    b1, b2, b3 = network['b1'], network['b2'], network['b3']
    a1 = np.dot(x, W1) + b1
    z1 = sigmoid(a1)
    a2 = np.dot(z1, W2) + b2
    z2 = sigmoid(a2)
    a3 = np.dot(z2, W3) + b3
    y = softmax(a3)
    return y
```

如果把它翻译成人话，就是：

1. 输入图片向量先经过第一层线性变换
2. 再经过 `sigmoid` 激活
3. 进入第二层线性变换
4. 再经过一次 `sigmoid`
5. 进入第三层线性变换
6. 最后通过 `softmax` 变成每个类别的概率

所以它是一个典型的三层神经网络推理过程。

## 5. `sigmoid` 和 `softmax` 在这里分别负责什么

你定义了：

```python
def sigmoid(x):
    return 1 / (1 + np.exp(-x))
```

它的作用是：

```text
给网络引入非线性，让模型不只是简单线性叠加
```

如果没有激活函数，多层线性层叠起来本质上还是线性模型。

而最后的 `softmax`：

```python
def softmax(a):
    c = np.max(a)
    exp_a = np.exp(a - c)
    sum_exp_a = np.sum(exp_a)
    y = exp_a / sum_exp_a
    return y
```

它的作用是：

```text
把最后一层输出的分数转换成一组和为 1 的类别概率
```

## 6. 为什么 `softmax` 要减去 `np.max(a)`

这一步特别值得记住：

```python
c = np.max(a)
exp_a = np.exp(a - c)
```

它是在做：

```text
数值稳定处理
```

因为如果 `a` 里某些值特别大，直接做 `np.exp(a)` 很容易溢出。

减去最大值以后：

- 最大那个元素会变成 0
- 其他元素会变成不大于 0 的数
- 指数运算就稳定得多

这一招非常经典，后面会经常见到。

## 7. 单样本预测那段循环在说明什么

你先写了：

```python
for i in range(len(x)):
    y = predict(network, x[i])
    p = np.argmax(y)
    if p == t[i]:
        accuracy_count += 1
```

这里的逻辑是：

1. 取第 `i` 张测试图片
2. 用网络算出 10 类概率
3. 用 `argmax` 找到概率最大的类别
4. 和真实标签比较
5. 统计正确个数

也就是说，分类预测最终真正用来给出结果的是：

```text
概率最大的那个类别
```

## 8. 为什么后面还要写“批处理”

你后面又写了：

```python
batch_size = 100
for i in range(0, len(x), batch_size):
    x_batch = x[i:i+batch_size]
    y_batch = predict(network, x_batch)
    p = np.argmax(y_batch, axis=1)
    accuracy_count += np.sum(p == t[i:i+batch_size])
```

这一步要说明的是：

```text
神经网络预测不一定要一张一张做，也可以一批一批一起做
```

为什么批处理更好？

因为矩阵运算一次处理一批数据，通常比逐个样本循环更高效，尤其在：

- NumPy 大矩阵计算
- GPU 张量计算

场景下差别会更明显。

所以批处理不仅用于训练，也同样适用于推理。

## 9. 这份 notebook 和前面 Softmax 回归的关系

你可以把这份 notebook 看成是前面分类任务的进一步展开。

Softmax 回归是：

```text
输入 -> 一层线性变换 -> softmax
```

而这里是：

```text
输入 -> 线性层 -> sigmoid -> 线性层 -> sigmoid -> 线性层 -> softmax
```

也就是说，这里比 Softmax 回归多了隐藏层和非线性激活，所以表达能力更强。

从这个角度看，它其实就是一个最基础的多层前馈分类网络。
