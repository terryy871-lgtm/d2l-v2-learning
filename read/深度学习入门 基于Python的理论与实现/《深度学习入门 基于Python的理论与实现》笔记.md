# 第3章神经网络
感知机和神经网络的主要区别就在于激活函数，激活活函数的目的是给网络加入非线性因素。
	激活函数：
		sigmoid函数：输出0到1之间的平滑曲线
		![[Pasted image 20260521173259.png]]
		阶跃函数：当输入超过0时，输出1，否则输出0
		relu函数：大于0则原样输出，小于0则输出0
	多维数组运算：通过输入矩阵与权重矩阵相乘，网络可以一次性处理大量数据，提升计算效率。
	输出层：
		回归问题（预测连续数值，如房价）：一般使用恒等函数（原样输出）。
		分类问题（预测类别，如猫狗识别）：使用 softmax 函数，将输出值转化为概率分布（所有类别的概率总和为 1）。

# 第4章神经网络的学习
损失函数是表示神经网络性能的“恶劣程度”的指标，即当前的神经网络对监督数据在多大程度上不拟合，在多大程度上不一致。
	均方误差
		![[Pasted image 20260521174720.png]]
	交叉熵误差
		![[Pasted image 20260521174741.png]]
由全部变量的偏导数汇总而成的向量称为梯度
梯度指向了各点处函数值减小最多的方向,通过不断地沿梯度方向前进，逐渐减小函数值的过程就是梯度法。
	W = W - 学习率 * 梯度
	学习率决定在一次学习中，应该学习多少，以及在多大程度上更新参数
	神经网络存在合适的权重和偏置，调整权重和偏置以便拟合训练数据的过程称为“学习”。神经网络的学习分成下面4个步骤。
		步骤1（mini-batch）从训练数据中随机选出一部分数据，这部分数据称为mini-batch。我们的目标是减小mini-batch的损失函数的值。
		步骤2（计算梯度）为了减小mini-batch的损失函数的值，需要求出各个权重参数的梯度。梯度表示损失函数的值减小最多的方向。
		步骤3（更新参数）将权重参数沿梯度方向进行微小更新。
		步骤4（重复）重复步骤1、步骤2、步骤3。

# 第六章 与学习相关的技巧
主要介绍让神经网络更好训练的一些技巧，包括参数更新、权重初始值、Batch Normalization、正则化和超参数验证。
	参数更新：
		SGD沿梯度方向更新参数，实现简单，但容易走“之”字路线。
		Momentum加入动量，减少震荡。
		AdaGrad会按参数自动调整学习率。
		Adam结合Momentum和AdaGrad，通常效果较好。
	权重初始值：
		权重不能全部初始化为0，否则神经元学不到不同特征。
		sigmoid、tanh常用Xavier初始值，ReLU常用He初始值。
		合适的初始值可以避免梯度消失或分布过度偏移。
	Batch Normalization：
		以mini-batch为单位调整激活值分布，使均值接近0、方差接近1。
		可以加快学习速度，减弱对初始值的依赖，并在一定程度上抑制过拟合。
	正则化：
		过拟合是训练集效果好、测试集效果差。
		权值衰减通过限制权重过大来抑制过拟合。
		Dropout在训练时随机删除部分神经元，也能缓解过拟合。
	超参数验证：
		学习率、batch大小、权值衰减系数等都属于超参数。
		超参数调整不能直接用测试集，要划分验证集。
		通常先设定大致范围，再随机采样，逐步缩小范围找到较优解。

# 第七章 卷积神经网络
主要介绍CNN的基本结构，以及卷积层和池化层的原理与实现。
	CNN整体结构：
		CNN在全连接层基础上加入了卷积层和池化层。
		常见顺序是 Convolution - ReLU - Pooling，最后再接Affine和Softmax输出结果。
		卷积层适合处理图像这类有空间结构的数据。
	卷积层：
		全连接层会忽略图像的形状信息，而卷积层可以保留通道、高、宽这些结构。
		卷积运算本质上是滤波器在输入数据上滑动，做乘积累加，再加上偏置。
		padding用于在边缘补0，防止输出尺寸过快缩小。
		stride表示滤波器移动步长，步幅越大，输出越小。
		处理图像时还要考虑通道数，输入和滤波器的通道数必须一致。
	池化层：
		池化是缩小空间大小的操作，常用的是Max Pooling。
		池化层没有要学习的参数，通道数一般不变。
		它可以压缩数据，同时对图像的微小位置变化更稳健。
	卷积层和池化层的实现：
		CNN中数据通常按(batch, channel, height, width)的4维形式保存。
		可以用im2col把输入展开成二维矩阵，这样卷积运算就能转成矩阵乘法。
		池化层也可以先展开，再取最大值来实现。
	CNN的实现与可视化：
		书中实现了一个简单的CNN，用于MNIST手写数字识别，并取得较高精度。
		卷积层前面几层通常提取边缘、斑块等低级特征，随着层数加深，会逐渐提取更复杂的纹理和部件信息。
