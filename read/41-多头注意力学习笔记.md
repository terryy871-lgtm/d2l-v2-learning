# 41 多头注意力学习笔记

对应文件：`Attention Mechanism/41_multihead_attention.ipynb`

这份笔记是结合你的文件 [41_multihead_attention.ipynb](</D:/Learn/d2l-test/Attention Mechanism/41_multihead_attention.ipynb>) 写的。它实现了 Transformer 中非常核心的多头注意力机制。

如果用一句话概括这一章：

```text
多头注意力就是把隐藏表示拆成多个子空间，并行做多组注意力，再把结果拼接回来
```

## 1. 为什么需要多头注意力

普通注意力只计算一组注意力权重。

但序列中可能同时存在多种关系。

例如一句话里，一个词可能需要关注：

- 前面的主语
- 后面的宾语
- 当前位置附近的修饰词
- 句法结构相关词
- 语义相近词

如果只有一个注意力头，模型可能很难同时表达这些关系。

多头注意力的思路是：

```text
让不同头在不同表示子空间里学习不同关注方式
```

## 2. MultiHeadAttention 的整体结构

notebook 中定义：

```python
class MultiHeadAttention(nn.Module):
```

主要组件是：

```python
self.W_q = nn.Linear(query_size, num_hiddens)
self.W_k = nn.Linear(key_size, num_hiddens)
self.W_v = nn.Linear(value_size, num_hiddens)
self.W_o = nn.Linear(num_hiddens, num_hiddens)
```

其中：

- `W_q`：生成 queries
- `W_k`：生成 keys
- `W_v`：生成 values
- `W_o`：把多个头拼接后的结果再映射一次

每个头内部使用：

```python
d2l.DotProductAttention(dropout)
```

也就是缩放点积注意力。

## 3. 多头注意力的计算流程

整体流程是：

1. 输入 queries、keys、values
2. 分别经过线性层投影
3. 把隐藏维度拆成多个头
4. 每个头独立做缩放点积注意力
5. 拼接所有头的输出
6. 经过输出线性层 `W_o`

可以写成：

```text
输入表示 -> 多个注意力头并行关注 -> 拼接 -> 输出表示
```

## 4. 为什么要拆隐藏维度

假设：

```text
num_hiddens = 100
num_heads = 5
```

那么每个头的维度是：

```text
100 / 5 = 20
```

不是每个头都使用完整 100 维，而是每个头处理 20 维子空间。

这样总计算量不会简单扩大 5 倍，同时能让模型学习多种注意力模式。

## 5. transpose_qkv 做什么

函数：

```python
def transpose_qkv(X, num_heads):
```

输入形状是：

```text
(batch_size, 查询数或键值对数, num_hiddens)
```

先 reshape：

```text
(batch_size, 查询数或键值对数, num_heads, num_hiddens / num_heads)
```

再 permute：

```text
(batch_size, num_heads, 查询数或键值对数, 每头维度)
```

最后合并 batch 和 head：

```text
(batch_size * num_heads, 查询数或键值对数, 每头维度)
```

这样做的好处是，可以直接调用普通点积注意力，把每个头当作 batch 中的一个样本并行处理。

## 6. transpose_output 做什么

多头注意力算完后输出形状是：

```text
(batch_size * num_heads, 查询数, 每头维度)
```

需要还原成：

```text
(batch_size, 查询数, num_hiddens)
```

这就是：

```python
transpose_output(X, num_heads)
```

它和 `transpose_qkv` 方向相反。

一个负责拆头，一个负责合并头。

## 7. valid_lens 为什么要复制

在多头注意力中，batch 维度被扩展成：

```text
batch_size * num_heads
```

所以有效长度也要复制：

```python
valid_lens = torch.repeat_interleave(valid_lens, repeats=self.num_heads, dim=0)
```

否则 mask 的 batch 数量和注意力输入对不上。

这一行经常容易漏。

如果漏掉，会出现维度错误，或者 mask 对错样本。

## 8. 输出线性层 W_o 的作用

多个头拼接后，还要经过：

```python
self.W_o(output_concat)
```

这不是多余步骤。

它可以把不同头的信息重新混合。

如果没有 `W_o`，不同头只是简单拼接，信息融合能力较弱。

`W_o` 让模型学会：

```text
如何组合不同注意力头捕捉到的信息
```

## 9. notebook 中的形状测试

notebook 设置：

```python
num_hiddens, num_heads = 100, 5
batch_size, num_queries = 2, 4

```

输入：

```text
X: (2, 4, 100)

```

输出应该是：

```text
(2, 4, 100)
```

也就是说，多头注意力不会改变 batch 数、query 数和最终隐藏维度。

它只是在内部拆成多个头计算。

## 10. 多头注意力和单头注意力的关系

单头注意力：

```text
一组 query-key-value 匹配
```

多头注意力：

```text
多组 query-key-value 投影 + 多组注意力 + 拼接融合
```

多头不是简单复制同一个注意力。

因为每个头有不同的线性投影参数，所以可以学习不同特征子空间。

## 11. 这章和 Transformer 的关系

Transformer 编码器和解码器都大量使用多头注意力。

编码器中是自注意力：

```text
Q = K = V = 输入序列
```

解码器中有两种注意力：

```text
掩蔽自注意力
编码器-解码器注意力
```

它们内部都可以使用多头注意力。

所以这一章是 Transformer 的关键组件准备。
