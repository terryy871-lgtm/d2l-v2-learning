如果用一句话概括这一章：

```text
自注意力让序列内部的每个词关注同一序列中的其他词，位置编码则告诉模型词的顺序
```

## 1. 什么是自注意力

普通注意力可以让一个序列去关注另一个序列。

例如机器翻译中：

```text
目标语言 query 关注源语言 key-value
```

自注意力则是：

```text
同一个序列自己关注自己
```

也就是：

```python
attention(X, X, X, valid_lens)
```

这里 queries、keys、values 都来自同一个输入 `X`。

## 2. 自注意力解决什么问题

RNN 按时间步顺序处理序列。

它天然知道顺序，但长距离依赖需要一步步传递。

CNN 可以并行，但需要多层卷积才能覆盖远距离位置。

自注意力可以让任意两个位置直接建立联系。

例如一句话中第 1 个词可以直接关注第 10 个词，不需要经过中间时间步逐层传递。

所以自注意力很适合建模长距离依赖。

## 3. 自注意力的形状

notebook 中：

```python
batch_size, num_queries = 2, 4
X = torch.ones((batch_size, num_queries, num_hiddens))
attention(X, X, X, valid_lens).shape
```

输入形状：

```text
(batch_size, num_steps, num_hiddens)
```

输出形状仍然是：

```text
(batch_size, num_steps, num_hiddens)
```

这说明自注意力会更新每个位置的表示，但不改变序列长度。

每个位置的新表示都融合了同一序列中其他位置的信息。

## 4. 自注意力为什么需要 mask

在编码器中，每个位置通常可以关注整个输入序列。

但在解码器训练时，当前位置不能看到未来词元。

例如生成第 3 个词时，不能提前看到第 4 个、第 5 个真实词。

所以解码器自注意力需要使用 mask：

```text
第 1 个位置只能看第 1 个
第 2 个位置只能看第 1-2 个
第 3 个位置只能看第 1-3 个
```

这就是后面 Transformer 解码器中的掩蔽自注意力。

## 5. 自注意力的一个问题：没有顺序感

自注意力本身主要看向量之间的相似度。

如果只给模型一组词向量，它并不知道词出现的先后顺序。

也就是说，自注意力对位置顺序不敏感。

但语言中顺序非常重要：

```text
dog bites man
man bites dog
```

词一样，顺序不同，意思完全不同。

所以 Transformer 必须额外加入位置信息。

这就是位置编码。

## 6. 位置编码是什么

notebook 定义：

```python
class PositionalEncoding(nn.Module):
```

它提前创建一个矩阵：

```python
self.P = torch.zeros((1, max_len, num_hiddens))
```

`P` 中每一行表示一个位置的编码向量。

前向传播时：

```python
X = X + self.P[:, :X.shape[1], :].to(X.device)
```

也就是把位置编码加到词元嵌入上。

这样每个词的表示就包含两部分：

```text
词本身的信息 + 它在句子中的位置信息
```

## 7. 正弦余弦位置编码

代码使用：

```python
self.P[:, :, 0::2] = torch.sin(X)
self.P[:, :, 1::2] = torch.cos(X)
```

偶数维使用 `sin`。

奇数维使用 `cos`。

不同维度使用不同频率。

这样每个位置都会得到一个独特的编码模式。

低维可能变化快，高维可能变化慢。

多个频率组合起来，就能表达绝对位置和相对位置关系。

## 8. 为什么不用简单编号

你可能会想，直接给第 1 个词加 1、第 2 个词加 2 不就行了吗？

问题是简单编号尺度会随着句子长度变大，而且不容易和词向量自然融合。

正弦余弦编码有几个优点：

1. 数值范围稳定在 `[-1, 1]`
2. 可以扩展到训练时没见过的更长位置
3. 不同频率能表达多尺度位置信息
4. 相对位置关系可以通过三角函数结构被模型利用

所以经典 Transformer 使用这种固定位置编码。

## 9. 位置编码曲线图怎么看

notebook 中画了某些维度随位置变化的曲线：

```python
d2l.plot(torch.arange(num_steps), P[0, :, 6:10].T)
```

横轴是位置。

纵轴是编码值。

不同列代表不同编码维度。

你会看到不同维度的曲线周期不同。

这说明位置编码不是单一节奏，而是多个频率的组合。

## 10. 二进制示例的作用

notebook 打印：

```python
for i in range(8):
    print(f'{i}的二进制是：{i:>03b}')
```

这个示例帮助理解“不同维度以不同周期变化”。

二进制中低位变化快，高位变化慢。

位置编码也类似：

```text
有些维度快速变化，有些维度缓慢变化
```

这样组合起来可以区分不同位置。

## 11. 位置编码热力图

最后：

```python
d2l.show_heatmaps(P, xlabel='Column (encoding dimension)', ylabel='Row (position)')
```

横轴是编码维度。

纵轴是位置。

颜色表示编码值大小。

这张图可以整体观察位置编码矩阵的结构。

不同位置的颜色模式不同，说明位置编码确实为每个位置提供了可区分的信息。

## 12. 自注意力和位置编码如何配合

自注意力负责建模词和词之间的关系。

位置编码负责提供顺序信息。

组合起来就是：

```text
模型既知道每个词是什么，也知道每个词在哪里
```

没有位置编码，自注意力会丢失顺序。

没有自注意力，位置编码也只是附加信息，不能实现强大的全局依赖建模。

## 13. 这份 notebook 你最应该记住什么

学完这一章，最重要的是记住：

1. 自注意力中 query、key、value 都来自同一个序列
2. 自注意力能让任意位置直接关注任意位置
3. 自注意力本身没有天然顺序感
4. 位置编码把位置信息加到词元嵌入中
5. 正弦余弦位置编码使用不同频率表达位置
6. Transformer 依靠自注意力和位置编码共同处理序列

如果最后只留一句话：

