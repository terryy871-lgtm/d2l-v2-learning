- 模型参数在 PyTorch 里到底是怎么保存的
- 怎么访问某一层的权重和偏置

- 为什么模型嵌套以后参数依然能被找到

如果用一句话概括这一章：

```text
参数管理这一章的核心是学会把模型当成一个“带很多可追踪参数的模块树”来看，而不是只把它当成能跑前向传播的黑盒
```

## 1. 先用人话理解“参数管理”在管什么

前一节“层和块”主要解决的是：

```text
模型结构怎么搭
```

这一节开始解决的是：

```text
模型搭好之后，里面那些权重和偏置怎么查看、初始化、修改和复用
```

这很重要，因为训练神经网络，本质上训练的就是参数。

对线性层来说，最典型的参数就是：

- `weight`
- `bias`

如果你不会查看和操作参数，就很难真正理解模型是怎么工作的。

## 2. 最开始这个网络长什么样

你一开始定义的是：

```python
net = nn.Sequential(nn.Linear(4, 8), nn.ReLU(), nn.Linear(8, 1))
```

这表示网络结构是：

```text
输入 4 维
-> 线性层映射到 8 维
-> ReLU
-> 线性层映射到 1 维
```

这里有两个线性层，所以也就意味着至少有两组参数：

- 第 1 个 `Linear(4, 8)` 的权重和偏置
- 第 2 个 `Linear(8, 1)` 的权重和偏置

而中间的 `ReLU` 没有可学习参数。

## 3. 怎么访问某一层的参数

你先写了：

```python
print(net[2].state_dict())
```

这里 `net[2]` 表示：

- `net[0]` 是第一个线性层
- `net[1]` 是 `ReLU`
- `net[2]` 是第二个线性层

所以你现在访问的是最后一个线性层。

输出类似：

```text
OrderedDict([
    ('weight', ...),
    ('bias', ...)
])
```

这就说明：

```text
一个层的参数通常会按名字保存在一个有序字典里
```

## 3.1 `state_dict()` 是什么

`state_dict()` 可以理解成：

```text
把当前模块里需要保存的状态，按“名字 -> 张量”的形式拿出来
```

对于线性层来说，最核心的状态就是：

- 权重 `weight`
- 偏置 `bias`

以后保存模型、加载模型时，`state_dict` 都非常重要。

## 4. 为什么 `bias` 不是普通张量

你接着看了：

```python
print(type(net[2].bias))
print(net[2].bias)
print(net[2].bias.data)
```

输出里能看到：

- `type(net[2].bias)` 是 `torch.nn.parameter.Parameter`

这说明：

```text
模型参数不是普通 Tensor，而是 Parameter
```

## 4.1 `Parameter` 和普通 Tensor 的区别

你现在可以先这样理解：

- 普通 `Tensor` 只是一个张量
- `Parameter` 是“会被 Module 自动登记成可训练参数的张量”

只要你把它挂到 `nn.Module` 里，PyTorch 就会默认把它当成模型要训练的东西。

所以：

```text
Parameter = Tensor + “这是模型参数，请跟踪我”
```

## 4.2 `.data` 在看什么

```python
net[2].bias.data
```

这一步拿到的是参数底层存的数值张量。

你可以把它理解成：

```text
只看这个参数当前的数值，不强调它作为 Parameter 的那层“包装身份”
```

在入门阶段，这样看参数值很直观。

不过从更规范的 PyTorch 写法来说，后面通常会更谨慎地使用 `.data`，因为它会绕开 autograd 的一部分机制。

这一章里先把它理解成“直接看参数值”就够了。

## 5. 怎么一次性查看所有参数

你后面写了：

```python
print(*[(name, param.shape) for name, param in net[0].named_parameters()])
print(*[(name, param.shape) for name, param in net.named_parameters()])
```

这段代码非常值得掌握。

## 5.1 `named_parameters()` 在做什么

它会遍历模块里的所有参数，并返回：

```text
参数名 + 参数本身
```

对于 `net[0]` 这种单层来说，输出类似：

- `weight`, `(8, 4)`
- `bias`, `(8,)`

这很好理解：

- 输入维度是 4
- 输出维度是 8

所以权重矩阵形状是：

```text
(8, 4)
```

因为每个输出神经元都要对应 4 个输入权重。

## 5.2 对整个网络调用 `named_parameters()` 有什么不同

当你对整个 `net` 调用时，输出会变成类似：

- `0.weight`
- `0.bias`
- `2.weight`
- `2.bias`

这里的名字为什么带前缀？

因为 PyTorch 会把：

```text
模块在网络里的层级路径
```

也编码进参数名里。

这里的：

- `0.weight` 表示第 0 层的权重
- `2.bias` 表示第 2 层的偏置

这其实已经在暗示你一个很重要的事实：

```text
PyTorch 能在整个模型树里定位每个参数
```

## 6. 直接从 `state_dict` 里取参数是什么意思

你又写了：

```python
net.state_dict()['2.bias'].data
```

这说明：

```text
不仅可以从层对象出发找参数，也可以直接通过参数名字从整个模型的状态字典里取
```

这两种视角都很重要：

- 从层对象出发：适合理解某个模块内部结构
- 从全局名字出发：适合保存、加载、遍历和统一管理

## 7. 为什么嵌套模型里也能找到参数

后面你定义了两个函数：

```python
def block1():
    return nn.Sequential(nn.Linear(4, 8), nn.ReLU(),
                         nn.Linear(8, 4), nn.ReLU())

def block2():
    net = nn.Sequential()
    for i in range(4):
        net.add_module(f'block {i}', block1())
    return net
```

然后又定义了：

```python
rgnet = nn.Sequential(block2(), nn.Linear(4, 1))
```

这个结构看起来已经比前面复杂很多了。

## 7.1 这个嵌套结构到底长什么样

它本质上是：

1. 外层一个 `Sequential`
2. 第 0 个位置是 `block2()`
3. `block2()` 里面又有 4 个 `block1()`
4. 每个 `block1()` 里面又有两层线性层和两个 `ReLU`
5. 最后外层再接一个 `Linear(4, 1)`

也就是说，它是一棵模块树，不是简单单层列表。

这也就是为什么打印 `rgnet` 时，会看到一层套一层的结构。

## 7.2 为什么还能这样访问参数

你写了：

```python
rgnet[0][1][0].bias.data
```

这看起来有点绕，但拆开就清楚了：

- `rgnet[0]`：外层第一个大块，也就是 `block2()`
- `rgnet[0][1]`：`block2()` 里的第二个 `block1()`
- `rgnet[0][1][0]`：这个 `block1()` 里的第一层 `Linear`
- `.bias.data`：取它的偏置值

这说明：

```text
即使模型嵌套得比较深，参数依然可以沿着模块层级一步步精确定位
```

## 8. 参数初始化到底是在初始化什么

这部分是整章非常实用的内容。

你先定义了：

```python
def init_normal(m):
    if type(m) == nn.Linear:
        nn.init.normal_(m.weight, mean=0, std=0.01)
        nn.init.zeros_(m.bias)
```

然后：

```python
net.apply(init_normal)
```

## 8.1 `apply()` 在做什么

`apply()` 的作用可以理解成：

```text
把某个函数递归地应用到当前模块及其所有子模块上
```

所以这里的意思就是：

```text
遍历整个网络，只要遇到 Linear 层，就按你写的规则初始化
```

## 8.2 正态分布初始化是什么意思

```python
nn.init.normal_(m.weight, mean=0, std=0.01)
```

这表示：

- 权重从均值为 0、标准差为 0.01 的正态分布中采样

而：

```python
nn.init.zeros_(m.bias)
```

表示偏置全部初始化成 0。

这是一种很常见、很基础的初始化方式。

## 9. 常数初始化在说明什么

你又写了：

```python
def init_constant(m):
    if type(m) == nn.Linear:
        nn.init.constant_(m.weight, 1)
        nn.init.zeros_(m.bias)
```

这说明权重初始化不一定非要随机，也可以：

```text
全部直接设成某个固定值
```

这在真实训练里通常不是最佳选择，但它很适合做演示，因为结果非常直观。

你打印后看到权重全是 `1`，偏置是 `0`，就能明确理解：

```text
初始化本质上就是在训练开始前给参数一个起点
```

## 10. 为什么不同层可以用不同初始化方法

接着你定义了：

```python
def init_xavier(m):
    if type(m) == nn.Linear:
        nn.init.xavier_uniform_(m.weight)

def init_42(m):
    if type(m) == nn.Linear:
        nn.init.constant_(m.weight, 42)
```

然后只对不同层分别调用：

```python
net[0].apply(init_xavier)
net[2].apply(init_42)
```

这一步很重要，因为它说明：

```text
初始化不仅可以“对整个网络统一处理”，也可以“针对某一层单独处理”
```

## 10.1 Xavier 初始化是什么直觉

你现在不用记复杂公式，先记直觉就够了：

```text
Xavier 初始化是在尽量让信号在网络层间传播时不要过大也不要过小
```

它是一种比“随便随机一下”更讲究的初始化方法。

## 10.2 这一步为什么能看出初始化是可控的

因为你让：

- 第一个线性层用 Xavier
- 第二个线性层直接全设成 42

所以打印出来时，两层权重明显不一样。

这说明初始化不是黑盒，而是：

```text
我们可以根据需要，精确控制不同层的初始参数分布
```

## 11. 自定义初始化函数在说明什么

你写的这段也很有意思：

```python
def my_init(m):
    if type(m) == nn.Linear:
        print("Init", *[(name, param.shape)
                        for name, param in m.named_parameters()][0])
        nn.init.uniform_(m.weight, -10, 10)
        m.weight.data *= m.weight.data.abs() >= 5
```

这里做了三件事：

1. 打印当前正在初始化的层
2. 先把权重均匀初始化到 `[-10, 10]`
3. 再把绝对值小于 5 的权重置成 0

这其实是在告诉你：

```text
初始化函数完全可以按你自己的规则来写，不一定只能用官方现成模板
```

也就是说，参数初始化本质上就是对参数张量进行赋值和变换。

## 11.1 为什么输出里会看到很多 0

因为你这句：

```python
m.weight.data *= m.weight.data.abs() >= 5
```

相当于做了一个掩码筛选：

- 绝对值大于等于 5 的保留
- 绝对值小于 5 的乘上 0

所以最后矩阵里会出现很多 `0`。

这一步挺像“稀疏化”的演示。

## 12. 手动改参数到底在改什么

你后面直接写了：

```python
net[0].weight.data[:] += 1
net[0].weight.data[0, 0] = 42
```

这说明：

```text
参数本质上就是张量，所以你可以像改普通张量一样直接改它们的值
```

第一句表示：

- 把这一层所有权重都加 1

第二句表示：

- 把第一行第一列那个具体权重直接改成 42

这很直观地说明了：

```text
模型参数并不神秘，它们就是一堆可以被索引、查看、修改的数值
```

## 13. 参数共享到底是什么意思

最后一部分是整章最容易让人真正理解“共享层”的地方。

你写了：

```python
shared = nn.Linear(8, 8)
net = nn.Sequential(
    nn.Linear(4, 8), nn.ReLU(),
    shared, nn.ReLU(),
    shared, nn.ReLU(),
    nn.Linear(8, 1)
)
```

这里最关键的点是：

```text
你不是创建了两个一模一样的 Linear(8, 8)，而是把同一个 shared 层对象用了两次
```

这就意味着：

```text
第 2 层和第 4 层其实引用的是同一组参数
```

## 13.1 为什么一开始比较结果全是 True

你写了：

```python
print(net[2].weight.data[0] == net[4].weight.data[0])
```

得到全是 `True`，这说明：

```text
两处看到的权重值完全一致
```

## 13.2 为什么改一个，另一个也跟着变

你继续写：

```python
net[2].weight.data[0, 0] = 100
print(net[2].weight.data[0] == net[4].weight.data[0])
```

结果还是全是 `True`。

这不是因为“碰巧两个层同步更新了”，而是因为：

```text
它们本来就是同一个层对象，所以访问的就是同一块参数内存
```

这才是参数共享最本质的地方。
