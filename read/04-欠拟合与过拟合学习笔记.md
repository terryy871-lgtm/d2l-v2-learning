```text
机器学习不仅要学会训练集，还要在没见过的新数据上表现稳定
```

这就是“泛化能力”的核心。

## 1. 先用一句人话理解欠拟合和过拟合

这一章研究的不是“模型能不能训练”，而是：

```text
模型学得是不是刚刚好
```

可能出现三种情况：

### 1. 正常拟合

- 训练集学得不错
- 测试集也表现不错

这说明模型复杂度合适，学到的规律比较有效。

### 2. 欠拟合

- 训练集都学不好
- 测试集自然也学不好

这说明模型太简单，连训练数据里的基本规律都没抓住。

### 3. 过拟合

- 训练集学得特别好
- 测试集却不好

这说明模型把训练数据里的“规律”和“噪声”一起记住了，导致泛化能力变差。

所以：

```text
欠拟合 = 模型太弱
过拟合 = 模型太强且学得太死
```

## 2. 这份 notebook 的核心思想

你的 notebook 用的是一个非常经典的思路：

```text
先人为构造一个有真实规律的数据集
再用不同复杂度的模型去拟合
最后观察训练损失和测试损失的变化
```

它通过三个实验来对比：

1. 三阶多项式拟合：正常
2. 线性函数拟合：欠拟合
3. 高阶多项式拟合：过拟合

这三个实验很适合你建立一个重要认识：

```text
模型不是越复杂越好，也不是越简单越好，而是要和任务复杂度匹配
```

## 3. 整个 notebook 在做什么

你的 notebook 主线可以概括成：

1. 构造一个多项式数据集
2. 把它转成 PyTorch tensor
3. 定义评估损失函数
4. 定义训练函数
5. 用三种不同复杂度的输入特征做实验
6. 对比训练损失与测试损失曲线

它最重要的不是“模型结构”，而是“实验设计”。

## 4.2 生成数据集

```python
max_degree = 20  # 多项式的最大阶数
n_train, n_test = 100, 100  # 训练和测试数据集大小
true_w = np.zeros(max_degree)  # 分配大量的空间
true_w[0:4] = np.array([5, 1.2, -3.4, 5.6])

features = np.random.normal(size=(n_train + n_test, 1))
np.random.shuffle(features)
poly_features = np.power(features, np.arange(max_degree).reshape(1, -1))
for i in range(max_degree):
    poly_features[:, i] /= math.gamma(i + 1)  # gamma(n)=(n-1)!
# labels的维度:(n_train+n_test,)
labels = np.dot(poly_features, true_w)
labels += np.random.normal(scale=0.1, size=labels.shape)
```

这一段是整份 notebook 最关键的实验构造部分。

### 先看实验意图

这里不是直接拿真实世界的数据，而是：

```text
我们自己造一个已知规律的数据集
```

这样做的好处是：

- 我们知道真实规律是什么
- 所以更容易判断模型到底学得怎么样

### `max_degree = 20`

表示：

- 最多构造到 20 阶多项式特征

也就是说，后面可以得到这样的特征：

```text
1, x, x^2, x^3, ..., x^19
```

### `n_train, n_test = 100, 100`

表示：

- 训练集 100 条
- 测试集 100 条

这样做是为了明确区分：

- 模型在训练数据上的表现
- 模型在未见数据上的表现

### `true_w`

```python
true_w = np.zeros(max_degree)
true_w[0:4] = np.array([5, 1.2, -3.4, 5.6])
```

这里藏着“真实规律”。

意思是：

- 真正起作用的只有前 4 个系数
- 更高阶的项真实权重其实是 0

所以真实模型本质上是一个三阶多项式：

```text
y = 5 + 1.2x - 3.4x^2/2! + 5.6x^3/3! + 噪声
```

也就是说：

```text
真实规律并不复杂，它本质上只需要三阶多项式就能表示
```

这也是为什么后面“三阶多项式拟合”会效果最好。

### `features`

```python
features = np.random.normal(size=(n_train + n_test, 1))
```

这里生成的是输入 `x`。

共有：

```text
200 个样本
```

每个样本只有一个原始输入特征。

### `np.random.shuffle(features)`

打乱顺序。

虽然这里影响不大，但可以避免数据有固定顺序偏差。

### `poly_features`

```python
poly_features = np.power(features, np.arange(max_degree).reshape(1, -1))
```

这一句特别重要。

它的作用是：

```text
把原始的一维输入 x 扩展成多项式特征
```

比如一个样本原来只有：

```text
x
```

现在会变成：

```text
[1, x, x^2, x^3, ..., x^19]
```

这就等价于人为给模型提供了更复杂的表达能力。

### 为什么还要除以 `gamma(i + 1)`

```python
poly_features[:, i] /= math.gamma(i + 1)
```

因为：

```text
gamma(n) = (n-1)!
```

所以这里本质上是在做：

```text
x^i / i!
```

这样处理有一个好处：

- 避免高次项数值爆炸得太快
- 让不同阶的特征数值更稳定一些

### `labels`

```python
labels = np.dot(poly_features, true_w)
labels += np.random.normal(scale=0.1, size=labels.shape)
```

这两句表示：

1. 按真实权重生成标签
2. 再加一点噪声

这样得到的数据更像真实世界：

- 有规律
- 但又不完全完美

## 4.3 转成 tensor

```python
true_w, features, poly_features, labels = [torch.tensor(x, dtype=
    torch.float32) for x in [true_w, features, poly_features, labels]]

features[:2], poly_features[:2, :], labels[:2]
```

这一步是在把 NumPy 数据转成 PyTorch tensor。

因为后面模型训练要用 PyTorch，所以数据必须是 tensor。

### 为什么都转成 `float32`

这是深度学习里最常见的浮点类型：

- 足够精度
- 运算效率也比较高

### `features[:2], poly_features[:2, :], labels[:2]`

这一句通常是为了观察前两个样本。

你可以把它理解成：

- 看一眼原始输入长什么样
- 看一眼多项式特征展开后是什么样
- 看一眼标签大概是多少

## 4.4 评估损失函数

```python
def evaluate_loss(net, data_iter, loss):  #@save
    """评估给定数据集上模型的损失"""
    metric = d2l.Accumulator(2)  # 损失的总和,样本数量
    for X, y in data_iter:
        out = net(X)
        y = y.reshape(out.shape)
        l = loss(out, y)
        metric.add(l.sum(), l.numel())
    return metric[0] / metric[1]
```

这一段是在定义：

```text
如何在一个数据集上计算平均损失
```

### 为什么要单独写这个函数

因为训练时我们不只关心训练损失，还关心：

- 测试损失

只有把训练集和测试集都评估出来，才能判断：

- 是正常拟合
- 还是欠拟合
- 还是过拟合

### `metric = d2l.Accumulator(2)`

这里累计两个量：

1. 总损失
2. 总样本数

最后用：

```python
metric[0] / metric[1]
```

得到平均损失。

### `y = y.reshape(out.shape)`

这一步是为了让标签形状和模型输出形状一致。

防止后面算损失时因为维度不匹配报错。

## 4.5 定义训练函数

```python
def train(train_features, test_features, train_labels, test_labels,
          num_epochs=400):
    loss = nn.MSELoss(reduction='none')
    input_shape = train_features.shape[-1]
    # 不设置偏置，因为我们已经在多项式中实现了它
    net = nn.Sequential(nn.Linear(input_shape, 1, bias=False))
    batch_size = min(10, train_labels.shape[0])
    train_iter = d2l.load_array((train_features, train_labels.reshape(-1,1)),
                                batch_size)
    test_iter = d2l.load_array((test_features, test_labels.reshape(-1,1)),
                               batch_size, is_train=False)
    trainer = torch.optim.SGD(net.parameters(), lr=0.01)
    animator = d2l.Animator(xlabel='epoch', ylabel='loss', yscale='log',
                            xlim=[1, num_epochs], ylim=[1e-3, 1e2],
                            legend=['train', 'test'])
    for epoch in range(num_epochs):
        d2l.train_epoch_ch3(net, train_iter, loss, trainer)
        if epoch == 0 or (epoch + 1) % 20 == 0:
            animator.add(epoch + 1, (evaluate_loss(net, train_iter, loss),
                                     evaluate_loss(net, test_iter, loss)))
    print('weight:', net[0].weight.data.numpy())
```

这一段是 notebook 的训练主干。

### 为什么这里还是线性层

这一点非常重要。

这里虽然研究的是“多项式拟合”，但模型写成：

```python
nn.Linear(input_shape, 1, bias=False)
```

仍然只是一个线性层。

为什么这样还能拟合多项式？

因为真正的“复杂度”不是来自网络层数，而是来自：

```text
输入特征已经被扩展成多项式特征了
```

也就是说，模型形式仍然是线性的：

```text
y = w0*1 + w1*x + w2*x^2 + ...
```

只是输入已经变成了多项式空间。

### `loss = nn.MSELoss(reduction='none')`

这里用的是均方误差损失。

因为这是一个回归问题，不是分类问题。

### `input_shape = train_features.shape[-1]`

这一句的作用是：

- 自动读取输入特征维度

比如：

- 如果只用 2 个特征，就是线性拟合
- 如果用 4 个特征，就是三阶多项式拟合
- 如果用 20 个特征，就是高阶多项式拟合

### 为什么 `bias=False`

注释里已经写得很关键：

```python
# 不设置偏置，因为我们已经在多项式中实现了它
```

因为多项式特征里第一项本身就是：

```text
1
```

对应的权重已经相当于偏置项了。

所以这里不需要额外再开一个 bias。

### `batch_size = min(10, train_labels.shape[0])`

表示：

- batch size 最多取 10

这里训练集只有 100 条数据，所以这个设置是合理的。

### `train_iter` 和 `test_iter`

这里分别构造：

- 训练集 DataLoader
- 测试集 DataLoader

目的是为了同时观察：

- 模型在训练集上的表现
- 模型在测试集上的表现

### `trainer = torch.optim.SGD(...)`

优化器仍然是 SGD。

说明这一章关注的重点不在优化器本身，而在：

```text
模型复杂度与泛化能力的关系
```

### `animator`

这里是为了画曲线。

重点是：

- 横轴：epoch
- 纵轴：loss
- 同时画出 train loss 和 test loss

而且这里用了：

```python
yscale='log'
```

也就是对数坐标。

为什么？

因为损失变化范围可能很大，用对数坐标更容易观察曲线趋势。

### 训练循环

```python
for epoch in range(num_epochs):
    d2l.train_epoch_ch3(net, train_iter, loss, trainer)
    if epoch == 0 or (epoch + 1) % 20 == 0:
        animator.add(epoch + 1, (evaluate_loss(net, train_iter, loss),
                                 evaluate_loss(net, test_iter, loss)))
```

这一步每轮训练之后，会定期记录：

1. 训练损失
2. 测试损失

而这一章最关键的判断，恰恰就来自这两条曲线的关系。

### 最后打印权重

```python
print('weight:', net[0].weight.data.numpy())
```

这一句是为了看：

- 模型最后学到的权重大概是什么样

有时它可以帮助你直观看出：

- 哪些特征被真正利用了

## 5. 三个实验分别在说明什么

## 5.1 三阶多项式拟合（正常拟合）

```python
train(poly_features[:n_train, :4], poly_features[n_train:, :4],
      labels[:n_train], labels[n_train:])
```

这里选的是前 4 个特征：

```text
1, x, x^2/2!, x^3/3!
```

而真实数据恰好就是由前三阶多项式生成的。

所以：

```text
模型复杂度和真实规律正好匹配
```

这时通常会看到：

- 训练损失下降
- 测试损失也下降
- 两者都比较低

这就是“正常拟合”。

### 这告诉你什么

```text
合适的模型复杂度可以同时兼顾训练效果和泛化能力
```

## 5.2 线性函数拟合（欠拟合）

```python
train(poly_features[:n_train, :2], poly_features[n_train:, :2],
      labels[:n_train], labels[n_train:])
```

这里只用了前 2 个特征：

```text
1, x
```

也就是说模型只能拟合一个线性函数。

但真实数据是三阶多项式生成的，所以：

```text
模型太简单了
```

这时通常会看到：

- 训练损失降不下去
- 测试损失也高

而且两者往往都不够好。

这就是“欠拟合”。

### 欠拟合的核心特征

```text
训练集都学不好
```

这点一定要记住。

因为很多初学者会误以为：

```text
测试不好就是过拟合
```

其实不是。

如果训练集都没学好，更可能是欠拟合。

## 5.3 高阶多项式拟合（过拟合）

```python
train(poly_features[:n_train, :], poly_features[n_train:, :],
      labels[:n_train], labels[n_train:], num_epochs=1500)
```

这里使用了所有 20 维多项式特征。

而真实规律其实只需要前 4 维。

这就意味着：

```text
模型容量远大于真实任务需要
```

而且训练轮数还增加到了：

```text
1500
```

这更容易让模型把训练集中的噪声也记住。

所以通常会看到：

- 训练损失很低
- 测试损失反而较高，甚至后期上升

这就是“过拟合”。

### 过拟合的核心特征

```text
训练集学得太好了，但测试集不行
```

这说明模型不是“真正理解规律”，而是“把训练集记住了太多”。

## 6. 如何通过曲线判断三种情况

这章真正要你学会的，不是背定义，而是：

```text
看曲线判断模型状态
```

### 正常拟合

- 训练损失下降
- 测试损失也下降
- 两条曲线都比较低，差距不大

### 欠拟合

- 训练损失高
- 测试损失也高
- 两条曲线都不好

### 过拟合

- 训练损失很低
- 测试损失明显高于训练损失
- 两者差距越来越大

## 7. 这一章真正想让你建立的核心观念

你要记住下面这几句话。

### 7.1 训练误差低，不代表模型就好

因为模型可能只是：

```text
把训练集记住了
```

### 7.2 模型太简单不行，太复杂也不行

机器学习追求的不是：

```text
复杂度越大越好
```

而是：

```text
复杂度和任务匹配
```

### 7.3 泛化能力比单纯训练效果更重要

因为现实使用中，模型要面对的是：

```text
没见过的新数据
```

不是训练集本身。

## 9. 你现在最应该彻底理解的 5 个点

### 9.1 为什么真实规律是三阶多项式

因为 `true_w` 只有前 4 个系数非零。

### 9.2 为什么线性模型也能拟合多项式

## 10. 代码里用到的几个重要语法/函数

### `np.power`

```python
np.power(features, ...)
```

作用是：

- 逐元素求幂

### `math.gamma(i + 1)`

作用是：

- 计算阶乘相关值
- 因为 `gamma(n) = (n-1)!`

### `nn.MSELoss(reduction='none')`

作用是：

- 逐样本计算均方误差
- 不立即求平均

### `nn.Linear(input_shape, 1, bias=False)`

作用是：

- 构造一个线性层
- 不带偏置，因为特征里已经包含常数项

### `torch.optim.SGD`

作用是：

- 使用随机梯度下降更新参数

### `d2l.Animator`

作用是：

- 实时画训练损失和测试损失曲线

## 12. 最后用最简单的话总结

这一章最核心的思想是：

```text
机器学习不是把训练集学得越死越好，而是要学到对新数据也有用的规律
```
