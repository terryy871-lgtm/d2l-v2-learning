# 13 填充和步幅学习笔记

这份笔记是结合你的文件 [13_padding_stride.ipynb](</D:/Learn/d2l-test/Convolutional_Neural_Networks/13_padding_stride.ipynb>) 写的，目标是帮助你真正理解：

- 为什么卷积以后特征图会变小
- 什么是填充（padding）
- 什么是步幅（stride）
- 它们分别控制输出的什么性质
- 为什么卷积网络里经常要同时设置核大小、填充和步幅

如果用一句话概括这一章：

```text
填充和步幅决定了卷积层“看多大、走多快、输出多大”
```

## 1. 先用一句人话理解这一章在解决什么问题

上一章你已经看到：

```text
卷积核在图像上滑动一次，输出一张新的特征图
```

但如果直接这么滑，会出现两个现实问题：

### 问题 1：输出会越来越小

卷积核每做一次有效计算，都要求自己完整落在输入图像内部。

所以不加任何处理时，输出尺寸会比输入小。

如果网络叠很多层，特征图就会缩得很快。

### 问题 2：滑动太慢或太快都会影响结果

卷积核每次移动多少格，会直接决定：

- 输出有多密
- 计算量有多大
- 保留下来的空间信息有多少

这就是填充和步幅要解决的核心。

## 2. 填充（padding）到底是什么

填充就是在输入边缘补上一圈值，通常补 `0`。

你可以把它理解成：

```text
先给原图外面加一圈边框，再让卷积核去滑
```

这样做最直接的作用是：

```text
让卷积核在靠近边缘的位置也能完整计算
```

所以填充通常会让输出尺寸变大一些，或者至少不至于缩得太快。

## 3. notebook 里第一个例子为什么输出尺寸不变

你先写了：

```python
conv2d = nn.Conv2d(1, 1, kernel_size=3, padding=1)
X = torch.rand(size=(8, 8))
comp_conv2d(conv2d, X).shape
```

这里的卷积核大小是 `3 x 3`，填充是 `1`。

这意味着：

- 上下左右各补 1 圈
- 输入从 `8 x 8` 临时变成 `10 x 10`
- 再用 `3 x 3` 的核去卷

最后输出又回到 `8 x 8`。

这说明一个非常常见的规则：

```text
当卷积核是奇数大小时，padding 取 kernel_size // 2，往往可以保持高宽不变
```

比如：

- `3 x 3` 核配 `padding=1`
- `5 x 5` 核配 `padding=2`

这在卷积网络里特别常见。

## 4. 为什么 `(5, 3)` 的卷积核对应 `(2, 1)` 的填充

你后面写了：

```python
conv2d = nn.Conv2d(1, 1, kernel_size=(5, 3), padding=(2, 1))
```

这是二维情况下更一般的写法。

它表示：

- 高度方向卷积核大小是 5，所以补 2
- 宽度方向卷积核大小是 3，所以补 1

这样就能分别在两个方向上保持尺寸。

这也说明：

```text
padding 不一定要是一个数，也可以在高和宽两个方向分别设置
```

## 5. `comp_conv2d` 这个辅助函数在做什么

你的 notebook 里写了：

```python
def comp_conv2d(conv2d, X):
    X = X.reshape((1, 1) + X.shape)
    Y = conv2d(X)
    return Y.reshape(Y.shape[2:])
```

这个函数本质上只是为了方便看结果尺寸。

它做了两件事：

1. 把二维输入 `X` 临时改成四维，满足 `Conv2d` 的输入要求
2. 卷积完成后再把批量维和通道维去掉

所以你看到的 `.shape` 更容易和纸面上的高宽对应起来。

## 6. 步幅（stride）到底是什么

步幅表示的是：

```text
卷积核每次滑动时跨几格
```

如果 `stride=1`，表示每次移动一格。

如果 `stride=2`，表示每次跳两格。

它最直观的影响是：

```text
步幅越大，输出特征图越小
```

因为你采样的位置变稀疏了。

## 7. 为什么 `stride=2` 会让输出明显变小

你有一段代码是：

```python
conv2d = nn.Conv2d(1, 1, kernel_size=3, padding=1, stride=2)
comp_conv2d(conv2d, X).shape
```

虽然这里还保持了 `padding=1`，但因为步幅变成了 2，卷积核不再逐格移动，而是隔一个位置取一次值。

这就相当于：

```text
对空间位置做了下采样
```

所以输出的高和宽会大约减半。

这也是卷积神经网络里常见的“缩小特征图”方式之一。

## 8. 为什么步幅和池化都能缩小特征图

学到这里你会发现：

- 步幅大的卷积可以缩小特征图
- 后面要学的池化也可以缩小特征图

它们效果上有点像，但侧重点不同：

### 大步幅卷积

```text
一边提取特征，一边下采样
```

### 池化

```text
在已有特征上做汇总和压缩
```

所以它们在网络中承担的角色并不完全一样。

## 9. 最后一个例子在说明什么

你最后写了：

```python
conv2d = nn.Conv2d(1, 1, kernel_size=(3, 5), padding=(0, 1), stride=(3, 4))
```

这里说明的是：

```text
卷积层的高和宽两个方向，可以分别设置不同的核大小、填充和步幅
```

也就是说，二维卷积并不要求所有方向都对称。

这在一些特殊输入里很有用，比如：

- 文本
- 时序转二维表示的数据
- 宽高比例比较特别的图像

## 10. 这一章真正要记住的关系

这一章最重要的不是死背公式，而是形成直觉：

### 核大小（kernel size）

```text
决定每次看多大的局部区域
```

### 填充（padding）

```text
决定边缘怎么处理，以及输出是否容易变小
```

### 步幅（stride）

```text
决定卷积核滑动有多快，以及输出会压缩到什么程度
```

如果再浓缩一点：

```text
padding 主要影响边界和输出尺寸，stride 主要影响采样密度和下采样强度
```

## 11. 这份 notebook 你最应该记住什么

学完这一章，最关键的是记住：

1. 不加填充时，卷积通常会让特征图变小
2. 合理设置 padding 可以保持高宽不变
3. stride 控制卷积核移动步长
4. stride 越大，输出特征图通常越小
5. 二维卷积在高和宽方向上都可以分别设置参数

如果用一句话收尾：

```text
卷积层不只是“拿个核去扫图”，还要通过 padding 和 stride 精细控制特征图的空间变化
```
