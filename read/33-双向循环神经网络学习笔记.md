```text
双向 RNN 的核心思想是：同一段序列既从左往右读一遍，也从右往左读一遍，再把两边的信息合起来
```

## 1. 先用人话理解双向 RNN

普通 RNN 只按一个方向处理序列：

```text
x1 -> x2 -> x3 -> x4
```

这样每个时间步只能看到它前面的历史。

双向 RNN 会同时做两件事：

```text
正向：x1 -> x2 -> x3 -> x4
反向：x4 -> x3 -> x2 -> x1
```

然后把两个方向的隐藏状态结合起来。

这样每个位置的表示就同时包含：

- 左边上下文
- 右边上下文

## 2. 为什么要看未来上下文

很多任务中，理解当前位置需要左右两边的信息。

比如一句话：

```text
I saw a bank near the river
```

要理解 `bank` 是银行还是河岸，右边的 `river` 很重要。

普通单向 RNN 在读到 `bank` 时还没看到 `river`。

双向 RNN 可以利用右侧上下文，所以更适合做：

- 文本分类
- 序列标注
- 命名实体识别
- 机器翻译编码器

## 3. notebook 中如何定义双向 LSTM

代码中：

```python
lstm_layer = nn.LSTM(
    num_inputs,
    num_hiddens,
    num_layers,
    bidirectional=True
)
```

关键就是：

```python
bidirectional=True
```

它会让 PyTorch 创建两个方向的 LSTM：

- 一个正向 LSTM
- 一个反向 LSTM

每个方向都有自己的参数。

## 4. 双向会改变输出维度

如果普通 LSTM 的隐藏单元数是 `num_hiddens`，输出特征维度就是：

```text
num_hiddens
```

双向 LSTM 会把正向和反向输出拼接起来，所以输出维度通常变成：

```text
2 * num_hiddens
```

这也是为什么很多封装模型需要知道 RNN 是否是双向的。

如果后面接线性层，线性层输入维度也要跟着变。

## 5. 双向 RNN 为什么不总适合语言生成

这一章仍然用《时间机器》语言模型训练。

但要注意一个概念点：

```text
双向 RNN 在生成式语言模型中并不总是合理
```

因为真实生成文本时，我们通常只能从左到右生成。

生成下一个字符时，未来字符还不存在。

双向 RNN 更适合已经拿到完整输入序列的任务。

比如翻译中的编码器可以读完整源句子，因此可以用双向结构。

但自回归生成下一个词时，不能偷看未来。

## 6. 这份 notebook 为什么仍然有教学价值

虽然双向 RNN 不一定适合作为严格的自回归语言模型，但这份 notebook 仍然有价值。

它演示了：

- 如何设置 `bidirectional=True`
- 双向模型如何接入 `d2l.RNNLM`
- 深层双向 LSTM 如何训练
- 梯度裁剪仍然可以照常使用

所以重点不是“这个语言模型一定最合理”，而是学会双向 RNN 的使用方式。

## 7. 和深层 RNN 的关系

notebook 中同时设置了：

```python
num_layers = 2
bidirectional=True
```

这表示它既是深层的，又是双向的。

可以理解为：

```text
每一层都有正向和反向两条循环路径
```

模型容量会进一步增加。

训练成本也会更高。

## 8. 这份 notebook 你最应该记住什么

学完这一章，最重要的是记住：

1. 双向 RNN 同时从左到右和从右到左处理序列
2. `bidirectional=True` 会创建两个方向的循环层
3. 双向输出通常会把特征维度翻倍
4. 双向 RNN 适合需要完整上下文的任务
5. 自回归生成任务中不能随便使用未来信息

如果最后只留一句话：

```text
双向 RNN 的优势是理解完整序列，限制是它需要看到未来，因此不适合所有在线预测和逐步生成场景
```
